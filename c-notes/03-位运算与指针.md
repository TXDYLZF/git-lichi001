# 03 位运算与指针

## 一、位运算符

**结论**：直接对整数**二进制位**操作的运算符，共 6 个：`&` `|` `^` `~` `<<` `>>`。

### 六式演算（A = 11001010，B = 00001111）

| 运算符 | 名称 | 规则 | 结果 | 用途 |
|--------|------|------|------|------|
| `&` | 按位与 | 有 0 则 0 | 0000 1010 | **清零**（掩码） |
| `\|` | 按位或 | 有 1 则 1 | 1100 1111 | **置一** |
| `^` | 按位异或 | 不同为 1 | 1100 0101 | **翻转** |
| `~` | 按位取反 | 0↔1 | 0011 0101 | 取反 |
| `<<` | 左移 | 低位补 0 | 整体左移 | ×2 |
| `>>` | 右移 | 整体右移 | 整体右移 | ÷2 |

口诀：**与清零、或置一、异或翻转、移位乘除 2**。

### 掩码思想的来源

`n % 8 == n & 7`（仅无符号成立）——因为 8 是 2³，`% 8` 要的就是低 3 位，而 7 = `00000111` 恰好只放行低 3 位。

**推广**：`n % 2^k == n & (2^k - 1)`

### 优先级坑（实测）

```c
int x = 4;
printf("%d\n", x & 1 == 0);      /* 输出 0（错！） */
printf("%d\n", (x & 1) == 0);    /* 输出 1（对） */
```

原因：`==` 优先级**高于** `&`，实际算的是 `x & (1==0)` = `x & 0` = 0，恒为假。
gcc 只给 warning（`suggest parentheses`），**不报错**——最阴的一类错。

**优先级顺序**：移位 > 比较 > `&` > `^` > `|`，全部低于 `==`。位运算和判断混写，括号是必需品。

### 其他要点

- **负数右移**：有符号是算术右移（补符号位），无符号是逻辑右移（补 0）——想移位先用 `unsigned`
- **`~x = -x - 1`**（实测 `~7 = -8`）；反过来 `~x + 1 = -x`（取负 = 取反加一）
- **左移不回卷**：移出的高位直接丢，无警告
- **异或三性质**：`a^a=0`、`a^0=a`、交换律

### 追问预判

| 问题 | 答法 |
|------|------|
| `1 << n` 是什么？ | 生成"只有第 n 位是 1"的掩码，`1<<3 = 8 = 0b1000`。所有寄存器操作的基础 |
| 怎么打印二进制？ | 循环 `n >> i & 1` 从高位到低位逐位打印 |
| 位运算比乘除快多少？ | 移位是 1 个周期的硬件动作，整数除法几十个周期。编译器会把 `x*8` 优化成 `x<<3` |

## 二、解引用运算符

**结论**：`*` 作用在**指针**上，`*p` 访问 p 所指向的变量——可读可写。

```c
int a = 5;
int *p = &a;      /* p 存 a 的地址 */
printf("%d\n", *p);   /* 读：输出 5 */
*p = 30;              /* 写：a 变成 30 */
```

### `&` 与 `*` 互逆（实测）

- `*&a == a`（成立）
- `&*p == p`（成立）
- 方向相反：`&` 从变量到地址，`*` 从地址回变量

### 同一个 `*`，两种身份

| 位置 | 含义 | 例子 |
|------|------|------|
| **声明里** | 只标记"p 是指针" | `int *p;` |
| **表达式里** | 真正解引用 | `*p = 30;` |

`int *p, q;` 里 **q 只是普通 int**——`*` 跟变量名结合，不跟类型名结合。

### 两大禁区

- **野指针**：`int *p; *p = 5;` —— p 里是垃圾地址，未定义行为，Linux 上 `Segmentation fault`。规则：**定义指针必须当场初始化**，暂不指就 `int *p = NULL;`
- **解引用 NULL**：同样崩。防御写法 `if (p == NULL) return -1;`

### 追问预判

| 问题 | 答法 |
|------|------|
| `*&a` 为什么等于 a？ | `&` 从变量到地址、`*` 从地址回变量，一来一回抵消 |
| 解引用时类型不对会怎样？ | `double *pd = (double*)&a; *pd` 会把 4 字节按 8 字节规则重新解释，读出不相干的数还越界。**指针类型决定按几字节、按什么格式解释** |

### `*p++` 与 `(*p)++`（优先级实战）

**结论**：`*p++` 等价于 `*(p++)`——先取当前指向的值，再把指针后移；`(*p)++` 是先把指针解引用，再把指向的数据加 1。

```c
int arr[] = {10, 20, 30};
int *p = arr;

int x = *p++;     /* x = 10；p 指向 arr[1] */
printf("%d %d\n", x, *p);  /* 10 20 */

p = arr;
(*p)++;           /* arr[0] 变成 11，p 仍指向 arr[0] */
printf("%d\n", arr[0]);    /* 11 */
```

**原因**：后缀 `++` 的优先级**高于**一元 `*`，所以 `*p++` 里先绑定 `p++`；加了括号 `(*p)++` 才强制先解引用。

#### 实际应用场景

| 写法 | 什么时候用 | 典型场景 |
|---|---|---|
| `*p++` | **遍历数组/字符串时取当前元素再前进** | 数组求和、字符串拷贝 `while(*dst++ = *src++);`、DMA 缓冲区消费、解析命令字符 |
| `(*p)++` | **通过指针修改被指向的计数/数值** | 桶计数 `(*bucket)++`、引用传参累加 `void add(int *p){(*p)++;}`、传感器采样计数 |

#### 嵌入式高频：字符串/缓冲区搬运

```c
char dst[32], src[] = "hello";
char *d = dst, *s = src;
while ((*d++ = *s++) != '\0');   /* 先复制当前字符，再同时后移两个指针 */
```

#### 踩坑提醒

- `*p++` 和 `(*p)++` 都是**先使用后修改**（后置++），但作用对象不同：前者动指针，后者动数据。
- 不要写 `*p++ = (*p)++;` 这类一个表达式里对同一对象改两次的代码，属于**未定义行为**。
- 优先级拿不准就加括号，代码可读性比炫技重要。

## 三、逗号运算符

**结论**：多个表达式用逗号串起来，从左到右依次求值，**整个表达式的值取最后一个**。

```c
int a, b, c;
a = (b = 3, c = b + 2, c * 2);   /* a = 10, b = 3, c = 5 */
```

### 括号是命门（实测）

```c
int x;
x = 1, 2 + 3;     /* x = 1，不是 5！ */
```

因为逗号优先级**最低**（比 `=` 还低），被拆成 `(x = 1), (2 + 3);`。
**带括号取尾项，不带括号取首项。**

### 注意

- **函数参数里的逗号是分隔符**，不是逗号运算符。`f((a=1, a+1), b)` 里必须加括号
- **求值顺序**：逗号是 C 里少数明确规定**从左到右**的（还有 `&&`、`||`、`?:`）
- **实际用途**：for 循环里同时操作多变量 `for (i=0, j=n-1; i<j; i++, j--)`

## 四、嵌入式关联

### 寄存器操作四件套

```c
reg |=  (1 << n);     /* 置 1 */
reg &= ~(1 << n);     /* 清 0 */
reg ^=  (1 << n);     /* 翻转 */
if (reg & (1 << n))   /* 检测 */
```

### 直接操作硬件地址（解引用的终极用法）

```c
*(volatile unsigned int *)0x40023830 = 0x1;   /* 点亮 STM32 GPIO 时钟 */
```

拆开看：裸数字 `0x40023830` → 强转成指针 → `*` 解引用。和 `*p = 30` 是**同一个动作**，只是目标从普通内存换成外设寄存器。

### 取高低半字节

```c
high = (reg & 0xF0) >> 4;
low  =  reg & 0x0F;
```

### 环形缓冲区优化

`idx = (idx + 1) % BUF_SIZE;` 若 BUF_SIZE 取 2 的幂，可改为 `idx = (idx + 1) & (BUF_SIZE - 1);` —— 省掉一次除法。

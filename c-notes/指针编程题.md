# 指针编程题（动手写代码）

> 独立章节，配套 [07 指针专题笔记](07-指针专题：完整知识点与易错点.md) 与 [指针专题练习题](指针专题练习题.md)。
> 类型：**编程题**（要你写函数/程序的那种，区别于选择/简答/找错）。
> 难度梯度：先字符串基础（P1–P7）→ 内存与二级指针（P8）→ 数组与综合（P9–P10）。
> 全部参考实现经本机 gcc 实测（输出见每题「运行示例」）。考试写这类题时，**函数头 + 指针移动 + 循环终止条件**是得分点。
>
> ⚠️ **看示例前必读两条**：
> ① 凡函数内部会**写入**参数的题（P2、P4、P6、P7、P9），示例里的字符串参数一律指**可写的字符数组**（`char s[] = "..."`），**不能直接传字符串字面量**（`"abc"` 在只读段，写它会段错误，实测退出码 139）。
> ② 凡返回类型是 `void` 的函数（P4、P7、P9），调用时**必须单独成句**（`reverse_str(s);`），不能写进 `printf` 的参数里（`printf("%s", reverse_str(s))`），否则报 `error: invalid use of void expression`。

### P1. ★★ 用指针实现 `my_strlen`（求字符串长度）

**题目**：不调用库函数 `strlen`，用指针遍历字符串，返回字符个数（不含结尾 `\0`）。

**参考实现**
```c
int my_strlen(const char *s) {
    const char *p = s;
    while (*p)          // 没遇到 '\0' 就继续
        p++;
    return (int)(p - s); // 尾指针 - 首指针 = 长度
}
```

**运行示例**：`my_strlen("hello")` → `5`

**考点**：指针相减得到「相隔元素个数」；`const char*` 表示只读不写，更规范。

### P2. ★★ 用指针实现 `my_strcpy`（字符串拷贝）

**题目**：把 `src` 拷到 `dst`（含结尾 `\0`），返回 `dst`。

**参考实现**
```c
char *my_strcpy(char *dst, const char *src) {
    char *d = dst;
    while ((*d++ = *src++) != '\0')  // 边拷边移，拷到 '\0' 后循环结束
        ;
    return dst;
}
```

**运行示例**：`my_strcpy(buf, "world")` → `buf` 内容为 `"world"`

**考点**：`(*d++ = *src++) != '\0'` 是经典一行写法——先赋值，再判断是否为 `\0`，同时两个指针都后移。注意 **`dst` 要有足够空间**（无越界检查是易扣分点，可加长度参数）。

### P3. ★★ 用指针实现 `my_strcmp`（字符串比较）

**题目**：逐字符比较两字符串，相等返回 0；`a` 小于 `b` 返回负数，大于返回正数。

**参考实现**
```c
int my_strcmp(const char *a, const char *b) {
    while (*a && *a == *b) { a++; b++; }   // 跳过相同的前缀
    return (unsigned char)*a - (unsigned char)*b;
}
```

**运行示例**：`my_strcmp("abc","abd")` → `-1`；`my_strcmp("abc","abc")` → `0`

**考点**：用 `unsigned char` 强转再相减，避免符号字符比较出错（嵌入式里汉字/扩展字符常见坑）。循环终止条件 `*a && *a == *b` 同时处理「遇到不同字符」和「遇到 `\0`」。

### P4. ★★★ 用指针反转字符串（原地）

**题目**：不使用额外数组，原地反转字符串（如 `"abcdef"` → `"fedcba"`）。

**参考实现**
```c
void reverse_str(char *s) {
    char *p = s, *q = s;
    while (*q) q++;   // q 走到 '\0'
    q--;              // 回退一格到最后一个有效字符
    while (p < q) {   // 双指针从两端往中间收
        char t = *p; *p++ = *q; *q-- = t;
    }
}
```

**调用示例**（原地修改，参数必须是**可写数组**）：
```c
char s[] = "abcdef";   /* ✅ 数组，可写。不能写 char *s = "abcdef"（只读，会崩） */
reverse_str(s);        /* ✅ 单独一句调用 */
puts(s);               /* 输出 fedcba */
```

**❌ 两种典型错误**：
```c
printf("%s", reverse_str(s));    /* error: invalid use of void expression */
reverse_str("abcdef");           /* 编译能过，运行时段错误：往只读区写入 */
```

**考点**：双指针；`q` 先找到末尾再 `--`；循环条件 `p < q` 保证奇数长度时中间字符不交换。另需注意 `void` 有两层含义——既是"不返回值"，也提示这是**原地修改**（改的是调用者传进来的那块内存）。

### P5. ★★★ 用指针实现冒泡排序（int 数组）

**题目**：给定 `int` 数组首地址和元素个数，用指针写法升序排序。

**参考实现**
```c
void bubble(int *a, int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (*(a + j) > *(a + j + 1)) {       // 指针版 a[j] > a[j+1]
                int t = *(a + j);
                *(a + j) = *(a + j + 1);
                *(a + j + 1) = t;
            }
}
```

**运行示例**：`{5,2,9,1,7}` → `1 2 5 7 9`

**考点**：`a[j]` 完全等价于 `*(a + j)`，排序用指针写法就是这么换；嵌套循环趟数 `n-1-i` 是标准优化。

### P6. ★★★ 用指针实现 `my_strcat`（字符串拼接）

**题目**：把 `src` 接到 `dst` 末尾（含 `\0`），返回 `dst`。**假定 `dst` 空间足够**。

**参考实现**
```c
char *my_strcat(char *dst, const char *src) {
    char *d = dst;
    while (*d) d++;              // 先走到 dst 末尾
    while ((*d++ = *src++) != '\0')  // 从末尾开始拷 src
        ;
    return dst;
}
```

**调用示例**（`dst` 必须是**可写数组**，`src` 可以是字面量）：
```c
char buf[32] = "Hello ";   /* ✅ 不能写 char *buf = "Hello "，那个不能写 */
my_strcat(buf, "World");   /* ✅ 返回 dst，也可以 void 单独调用 */
puts(buf);                 /* 输出 Hello World */
```

**考点**：必须先让 `d` 走到 `dst` 的 `\0` 处再开始拷；否则会覆盖原内容。考点同 P2 的赋值写法。

### P7. ★★★ 删除字符串中所有指定字符（原地）

**题目**：删除字符串 `s` 中所有等于字符 `c` 的字符，原地完成，返回新串。如 `"a,b,c,d"` 删 `,` → `"abcd"`。

**参考实现**
```c
void del_char(char *s, char c) {
    char *p = s, *q = s;        // p=写指针, q=读指针
    while (*q) {
        if (*q != c)            // 不是要删的字符才写回去
            *p++ = *q;
        q++;                    // 读指针永远前移
    }
    *p = '\0';                  // 收尾补结束符
}
```

**调用示例**（原地修改，`s` 必须是**可写数组**）：
```c
char s[] = "a,b,c,d";
del_char(s, ',');      /* ✅ void 函数，单独一句；别写进 printf */
puts(s);               /* 输出 abcd */
```

**考点**：**快慢指针（双指针）** 经典模板——`q` 负责读，`p` 只在不删除时前进写。这是「数组/字符串原地删除」的通用套路，面试常考。

### P8. ★★★★ 二级指针：函数内 `malloc`，外部指针拿到内存

**题目**：写一个函数，在**函数内部**申请一块能装 `n` 个 `int` 的内存，并让**调用者的指针变量**指向它。

**参考实现**
```c
void alloc_ints(int **pp, int n) {
    *pp = (int *)malloc(n * sizeof(int));   // 改的是 *pp（即外部那个指针本身）
}

/* 调用方 */
int *blk = NULL;
alloc_ints(&blk, 3);   // 必须传 &blk（二级指针），不能传 blk
if (blk) {
    blk[0] = 10; blk[1] = 20; blk[2] = 30;
    free(blk); blk = NULL;
}
```

**运行示例**：申请 3 个 int 并赋值 → 输出 `10 20 30`

**考点**：为什么必须二级指针？C 是值传递——传 `int*` 只能改它**指向的数据**；要改「指针变量本身指向哪块内存」，必须传它的地址 `int**`。这是二级指针最实用的场景（嵌入式里动态配置缓冲区常用）。

### P9. ★★★ 用指针逆序 int 数组（原地）

**题目**：给定 `int` 数组首地址和长度，原地逆序（如 `{1,2,3,4,5}` → `{5,4,3,2,1}`）。

**参考实现**
```c
void reverse_arr(int *a, int n) {
    int *p = a, *q = a + n - 1;   // q 直接定位到末元素
    while (p < q) {
        int t = *p; *p++ = *q; *q-- = t;
    }
}
```

**运行示例**：`{1,2,3,4,5}` → `5 4 3 2 1`

**考点**：与 P4 同理的双指针；`q = a + n - 1` 指针算术定位末尾，比先走再回退更简洁。

### P10. ★★★★ 用指针统计字符串单词数

**题目**：以空格/制表符分隔，统计单词个数（首尾多余空白忽略）。如 `"  hi  embedded  c "` → `3`。

**参考实现**
```c
int count_words(const char *s) {
    int cnt = 0;
    const char *p = s;
    while (*p) {
        while (*p == ' ' || *p == '\t') p++;   // 跳过空白
        if (*p) {                              // 还有字符说明遇到一个单词
            cnt++;
            while (*p && *p != ' ' && *p != '\t') p++; // 跳过整个单词
        }
    }
    return cnt;
}
```

**运行示例**：`count_words("  hi  embedded  c ")` → `3`

**考点**：状态机式扫描——「跳过空白 → 遇到非空白算一个词 → 跳过这个词」。指针写法避免下标越界，嵌入式解析串口/配置字符串常用。

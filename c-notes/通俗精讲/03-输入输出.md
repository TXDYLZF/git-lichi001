# 03 输入输出（大白话版）

> 来源：QQ `03.md`（scanf / getchar）+ 工作台 `04-输入输出.md`
> 配套详版：[04-输入输出.md](../04-输入输出.md)

`printf` 往屏幕**输出**，`scanf`/`getchar` 从键盘**输入**。核心难点不在函数本身，而在**格式符对不对**、**漏没漏 &**、**缓冲区里残留的换行怎么处理**。

---

## 1. printf 常用格式符

| 格式符 | 含义 | 例子 |
|--------|------|------|
| `%d` | 十进制 int | `printf("%d", 10)` |
| `%c` | 单个字符 | `printf("%c", 'A')` |
| `%s` | 字符串（遇到 `\0` 停） | `printf("%s", "hi")` |
| `%f` | float/double（默认 6 位小数） | `printf("%f", 1.5)` |
| `%.2f` | 保留两位小数 | `printf("%.2f", 1.5)` |
| `%p` | 指针地址 | `printf("%p", p)` |
| `%zu` | `size_t`（sizeof 的返回类型） | `printf("%zu", sizeof(int))` |
| `%lld` | `long long` | `printf("%llu", n)` |

**坑**：`%f` 既能打 `float` 也能打 `double`（float 传参时自动提升成 double）；但 `scanf` 读 `float` 必须 `%f`、读 `double` 必须 `%lf`，**两边不一样**。

---

## 2. scanf：漏 & 是第一大坑

`scanf` 要的是「把输入写进哪个柜子」，所以**必须传地址**：

```c
int num;
scanf("%d", &num);     // ✅ 传地址
scanf("%d", num);      // ❌ 把 num 的值当地址，写飞了 → 段错误/未定义
```

读字符串 `char s[20]` 时 `s` 本身就是地址，**不用加 &**：

```c
char name[20];
scanf("%s", name);     // ✅ 数组名=首地址，不加 &
```

`scanf` 返回值 = **成功读入的项数**，失败时返回 `EOF`。可用它判输入是否合法：

```c
if (scanf("%d", &n) != 1) { printf("输入的不是数字!\n"); }
```

**课堂原话**：「用户的输入永远不可信」——考试/作业里一定要校验返回值，别假设用户乖乖输入。

---

## 3. 缓冲区残留：换行符 `\n` 偷吃后面的输入

`scanf("%d", ...)` 读完数字后，**回车键 `\n` 还留在输入缓冲区**。下一个 `scanf(" %c", &ch)`（注意 `%c` 前的空格）如果不处理，就会把 `\n` 读走。

```c
int n; char ch;
scanf("%d", &n);
scanf("%c", &ch);      // ❌ ch 拿到的是 '\n'，不是你想要的字符
```

**两种解法**：
1. `%c` 前加空格吃掉空白：`scanf(" %c", &ch);`
2. 用 `getchar()` 先消耗掉 `\n`

---

## 4. getchar：一次读一个字符

`int getchar(void)` 从输入流读一个字符，遇到文件结束或错误返回 `EOF`。常和循环配合：

```c
char ch;
do {
  ch = getchar();
  if (ch == '\n') continue;          // 跳过换行
  printf("you entered: %c\n", ch);
} while (ch != 'q');                  // 输入 q 退出
```

**注意**：`getchar` 返回 `int` 不是 `char`——因为它要能返回 `EOF`（通常是 -1），用 `char` 接会出问题，规范写法用 `int ch`。

## 5. 一张图：输入怎么进程序

```
键盘敲:  1 2 3 回车
              ↓
输入缓冲区:  ['1']['2']['3']['\n']     ← 回车也进来了
              ↓ scanf("%d") 拿走 123
缓冲区剩:   ['\n']                      ← 下一个 %c 会先吃到它！
```

## 自测
- `scanf("%d", num)` 为什么错？→ 少 `&`，应传地址 `&num`
- 读 `char name[20]` 为什么要 `scanf("%s", name)` 不加 `&`？→ 数组名本身就是首地址
- 为什么连续 `scanf` 有时会「跳过」输入？→ 上一个输入的 `\n` 残留在缓冲区，被下一个 `%c` 吃掉；用 `" %c"` 或 `getchar()` 化解
- `getchar()` 返回类型为什么是 `int` 不是 `char`？→ 要能表示 `EOF`(-1)

# 10 内存与动态分配（大白话版）

> 来源：QQ `04.md`（malloc/calloc/realloc）+ `13.md`（矩阵动态分配与释放）
> 配套详版：工作台 `07-指针专题` 第 8 节（动态内存）、`09-指针通俗精讲` 第 8、9 节

变量住哪儿？C 程序的内存大致分「栈」和「堆」两块。理解它，才懂 `malloc/free` 为什么存在、野指针为什么致命。

---

## 1. 栈 vs 堆（一句话）

| | 栈 stack | 堆 heap |
|---|---------|---------|
| 谁管理 | 编译器自动 | 程序员手动 |
| 生命周期 | 函数返回就回收 | `free` 之前一直在 |
| 大小 | 小（几 MB） | 大（看系统） |
| 典型用途 | 局部变量、数组 | 运行时才定大小的数据 |

```c
void f() {
  int x = 5;          // x 在栈上，f 返回就没了
  int buf[1000];      // 也在栈上
}
int *p = malloc(100); // 100 字节在堆上，得自己 free
```

**痛点**：栈上数组长度写死、函数一返回就没；想「运行时才决定多大」「函数返回后还要用」，就得去堆上 `malloc`。

## 2. 四件套：malloc / calloc / realloc / free

```c
#include <stdlib.h>
int *p = (int *)malloc(5 * sizeof(int));  // 借 5 个 int，内容随机（不初始化）
int *q = (int *)calloc(5, sizeof(int));   // 借 5 个 int，全部清 0
// 扩容/缩容：
int *r = (int *)realloc(p, 10 * sizeof(int)); // 改成 10 个 int（原数据保留）
free(r);  r = NULL;     // 还回去，立刻置 NULL 防悬空
```

- `malloc(n)`：借 n 字节，**不初始化**（里面是垃圾值）。
- `calloc(n, size)`：借 `n×size` 字节，**清零**——适合数组。
- `realloc(ptr, new)`：把 ptr 指向的内存**改大小**；可能搬家（返回新地址），所以要用返回值接：`ptr = realloc(ptr, ...)`。
- `free(ptr)`：**还内存**。借了必须还，否则内存泄漏。

**铁律**：`malloc/calloc/realloc` 之后**立刻判 `NULL`**（申请可能失败）；`free` 之后**立刻 `= NULL`**。

## 3. 三种危险指针（考试重灾区）

| 类型 | 怎么来的 | 后果 |
|------|---------|------|
| 野指针 | 没初始化就 `*p = 5` | 写进随机地址，段错误 |
| 悬空指针 | `free` 后没置 NULL 还在用 | 内存已归还，未定义行为 |
| NULL 指针 | 初始化/释放后置 NULL | 也崩，但能 `if (p==NULL)` 防御 |

```c
int *p = NULL;          // 暂不指就置 NULL（好习惯）
int *q = malloc(4);
// 忘了 free 就丢了 q → 泄漏
free(q); q = NULL;      // ✅ 还完置空
```

## 4. 二维矩阵动态分配（指针的指针）

`int matrix[3][4]` 是栈上连续的；想在堆上建「行数、列数都运行时定」的矩阵，用「指针数组」：

```c
int rows = 3, cols = 4;
int **matrix = (int **)malloc(rows * sizeof(int *));  // 先借 rows 个「行指针」
for (int i = 0; i < rows; i++)
  matrix[i] = (int *)malloc(cols * sizeof(int));      // 每行再借 cols 个 int

// 用：matrix[i][j] 和静态矩阵一模一样
// 释放：先释放每一行，再释放行指针数组（顺序不能反！）
for (int i = 0; i < rows; i++) free(matrix[i]);
free(matrix);
```

**释放顺序坑**：先 `free(matrix[i])` 每行，最后 `free(matrix)`。反过来先 free 外层，里面的行就找不回来、泄漏了。
**失败回滚**：某一行 `malloc` 失败时，要把前面已成功的行先 `free` 掉再退出（见 `13.md` 的 `createMatrix` 写法）。

三级/多维同理：`int ***cube` 是「指针的指针的指针」，一层层 `malloc`、反着一层层 `free`。

## 自测
- 栈上的数组和 `malloc` 的数组最大区别？→ 栈自动回收、大小写死；堆手动 free、可运行时定大小
- `calloc` 和 `malloc` 区别？→ calloc 自动清零，malloc 不初始化
- 释放二维矩阵为什么先 free 每一行？→ 先 free 外层就找不到各行的内存了，会泄漏
- `free(p)` 之后还要做啥？→ 立刻 `p = NULL` 防悬空

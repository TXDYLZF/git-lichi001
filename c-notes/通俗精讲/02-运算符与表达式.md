# 02 运算符与表达式（大白话版）

> 来源：QQ `03.md`（运算符 / 优先级 / 隐式转换）+ 工作台 `02-基础语法.md`
> 配套详版：[02-基础语法.md](../02-基础语法.md)

运算符就是「对柜子里的值动手」的动作。**凡比较必有结果**——关系/逻辑运算的结果是 0（假）或 1（真）。

---

## 1. 算术运算符

```
+  -  *  /  %  ++  --
```

- `/` 两个整数相除**只留整数部分**：`5 / 2 == 2`（不是 2.5）。想要小数，至少一边写成浮点：`5.0 / 2`。
- `%` 取余**只支持整数**；浮点取余用 `fmod(x, y)`（`<math.h>`）。
- `++a` 先加后用；`a++` 先用后加。

```c
int a = 1, b = 2;
printf("%d\n", a + b);     // 3
float c = 1.23;
printf("%f\n", a + c);     // 2.230000  （int 被提升成 float 再算）
int d = a + c;             // 2  （结果截断回 int，丢掉小数）
int h = b % a;             // 0
```

---

## 2. 隐式类型转换（小类型往大类型「升级」）

> 课堂原话：表达式结果按运算符两边**较大的类型**转换。

规则链（低 → 高）：`char/short` → `int` → `long` → `float` → `double`。
- `short`/`char` 参与运算先升成 `int`
- `int` 和 `long` 算 → `int` 升 `long`
- `int` 和 `float` 算 → `int` 升 `float`

**铁律**：混合类型运算结果类型 = 参与者里「最高」的那个。`int + float` 结果是 `float`，赋回 `int` 时**截断小数**（不是四舍五入）。

## 3. 关系 / 逻辑运算符

```
关系： ==  !=  >  <  >=  <=      （结果 0/1）
逻辑： &&  ||  !                  （与 / 或 / 非）
```

- C **没有 bool 类型**，认为「**非 0 皆真**」。
- `&&` 短路：左边为假，右边不执行；`||` 短路：左边为真，右边不执行（写 `if(p && p->x)` 防崩就靠它）。

```c
printf("%d\n", 1 + 2 == 3);          // 1（真）
printf("%d\n", 0.1 + 0.2 == 0.3);    // 0（假，浮点别用 ==）
int r = fabs(0.1 + 0.2 - 0.3) <= 1e-9; // 1（真，正确比法）
```

## 4. 位运算符（直接拨二进制位）

```
&  按位与      |  按位或      ^  按位异或
~  按位取反    << 左移        >> 右移
```

- `a & b`：对应位都为 1 才 1
- `a | b`：有 1 就 1
- `a ^ b`：不同为 1、相同为 0（**异或妙用**：`a ^= b; b ^= a; a ^= b;` 不借第三变量交换两数；同自己异或为 0）
- `<< n`：左移 n 位 ≈ 乘 2ⁿ；`>> n`：右移 ≈ 除 2ⁿ（**嵌入式最爱**，比乘除法快）
- `~a`：所有位取反（结果是负数，因为符号位也翻了）

```c
int a = 3, b = 5;
printf("%d\n", a & b);   // 1   (011 & 101 = 001)
printf("%d\n", a | b);   // 7   (011 | 101 = 111)
printf("%d\n", a ^ b);   // 6   (011 ^ 101 = 110)
printf("%d\n", a << 1);  // 6   (3*2)
printf("%d\n", ~a);      // -4  （取反后是负数）
```

**嵌入式关联**：置位/清位/取某一位全靠位运算，例如 `reg |= (1<<3)` 把第 3 位置 1，`reg &= ~(1<<3)` 清 0。

## 5. 赋值 / 条件 / 逗号

- 复合赋值：`+=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=`
- 条件（三元）：`条件 ? 真值 : 假值` —— 表达式，能直接当值用
- 逗号：顺次执行多个表达式，**返回最后一个的值**

```c
char r = 3 > 2 ? 'o' : 'n';      // 'o'
int x = (3 > 2) ? 1 : 0;
int a, b, c;
a = (b = 3, c = b + 2, c * 2);   // a = 10（逗号返回最后的 c*2=10）
```

## 6. 优先级速查（12 级，就近原则）

> 记不住就**加括号**。考试常挖「不加括号结果不同」的坑。

```
1  ()  []  .  ->          最高（先算成员/下标/调用）
2  ++ --  + -  !  ~  &  *  单目（含取地址&、解引用*）
3  算术  *  /  %
4  算术  +  -
5  <<  >>
6  <  >  <=  >=
7  ==  !=
8  &
9  ^
10 ||
11 ? :
12 =  += ...              最低（赋值，从右往左结合）
```

**两个必考坑**：
- `*` 和 `++` 同在第 2 级：`*p++` 是「先取 `*p`，再 p++」；`(*p)++` 是「p 指向的值 +1」。
- 赋值从**右往左**：`a = b = 3` 等价于 `a = (b = 3)`。

---

## 7. sizeof 与指针运算符

- `sizeof` 返回字节数，类型用 `size_t`（打印用 `%zu`）。
- `&` 取地址、`*` 解引用（多级指针要多个 `*`：`**p`、`***p`）。

```c
size_t s = sizeof(int);     // 4
int v = 10;
int *p = &v;
printf("%d\n", *p);        // 10
```

- `5 / 2` = ? → **2**（整数除法）。`5.0 / 2` = ? → **2.5**

- `reg |= (1<<3)` 干嘛用？→ 把第 3 位置 1（嵌入式置位）
- `*p++` 和 `(*p)++` 区别？→ 前者指针后移、后者值 +1

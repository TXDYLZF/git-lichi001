# 09 字符串与字符处理（大白话版）

> 来源：QQ `15.md`（字符串函数清单）+ 工作台 `08-字符串操作函数.md`（18 个函数逐个讲）
> 配套详版：[08-字符串操作函数.md](../08-字符串操作函数.md)

字符串 = **以 `'\0'` 结尾的字符数组**。这是 C 字符串的命门：所有字符串函数都靠 `'\0'` 判断「到哪结束」。

---

## 1. 两种写法，天差地别

```c
char *s = "hello";    // s 指向只读区的字面量，不能改（改了段错误）
char  t[] = "hello";  // t 是栈上的数组，内容能改
```

**遍历靠 `'\0'` 收尾**：

```c
char *p = t;
while (*p) { putchar(*p); p++; }   // 遇到 '\0'（值为0）停止
```

## 2. 核心函数速查（带坑）

| 函数 | 作用 | 必记坑 |
|------|------|--------|
| `strlen(s)` | 长度（**不含 `\0`**） | 和 `sizeof` 不同；`sizeof` 含 `\0` 和数组填充 |
| `strcpy(dst, src)` | 复制（含 `\0`） | **不检查目标大小**，溢出就炸 |
| `strncpy(dst, src, n)` | 最多复制 n 个 | **可能不补 `\0`**！目标要自己留/补结尾 |
| `strcat(dst, src)` | 拼接到 dst 末尾 | dst 必须够大；改 dst 的 `\0` 为 src 开头 |
| `strncat(dst, src, n)` | 最多拼 n 个 | 比 strcat 安全，会自动补 `\0` |
| `strcmp(a, b)` | 比大小，返回 <0/0/>0 | **别用 `==`** 比字符串（比的是地址）；相等才返回 0 |
| `strncmp(a,b,n)` | 只比前 n 个 | 前缀比较用 |
| `strchr(s, c)` | 找字符 c 第一次出现 | 返回指针或 NULL |
| `strrchr(s, c)` | 找字符 c 最后一次 | 同上 |
| `strstr(hay, needle)` | 找子串 | 返回指针或 NULL |
| `sprintf(buf, fmt, ...)` | 格式化写入字符串 | 同 printf 但写进 buf，**不检查溢出** |
| `snprintf(buf, n, fmt, ...)` | 限长格式化 | **安全版**：最多写 n-1 个，自动补 `\0` |
| `strtok(s, delim)` | 按分隔符切分 | **破坏原串**（把分隔符改成 `\0`），不可重入 |
| `strdup(s)` | 复制并返回堆上字符串 | 内部 malloc，**一定要 free**；需合适编译标准 |
| `puts(s)` / `fgets(s, n, stdin)` | 输出 / 安全读行 | `fgets` 会读入 `\n`，注意处理 |

## 3. 三个最高频坑（考试/作业必考）

**① `strcmp` 用 `==` 比 —— 错！**
```c
if (strcmp(a, b) == 0) ...   // ✅ 相等返回 0
if (a == b) ...               // ❌ 比的是两个地址，永远不对
```

**② `strncpy` 不补 `\0`**
```c
char dst[10];
strncpy(dst, "hello world!!", 10);  // 只抄前10个，没有 \0！
dst[9] = '\0';                      // ✅ 手动补结尾
```

**③ `strtok` 会改原串、且线程不安全**
```c
char s[] = "a,b,c";
char *p = strtok(s, ",");   // 第一次传原串
while (p) { printf("%s\n", p); p = strtok(NULL, ","); }  // 之后传 NULL
// 注意：s 已被破坏（逗号变成 \0），原串不能再用
```

## 4. 实战：统计单词数量（状态机）

> 课堂随堂任务。思路：用 `in_word` 标记「当前是否在单词里」，遇到字母且不在词中 → 单词数 +1、进词；遇到空格/标点 → 出词。

```c
#include <ctype.h>
int count_words(const char *s) {
  int count = 0, in_word = 0;
  for (int i = 0; s[i]; i++) {
    if (isalpha(s[i])) {          // 是字母
      if (!in_word) { count++; in_word = 1; }  // 刚进一个新词
    } else {
      in_word = 0;                // 不是字母 → 出词
    }
  }
  return count;
}
// "Hello, world!" → 2
```

这是**状态机**的雏形：程序在「词内 / 词外」两个状态间切换，比「数空格+1」稳（连续空格、开头结尾空格都不会错）。状态机也是函数指针的用武之地（见 `09-指针通俗精讲` 第 10.5）。

## 自测
- 字符串结尾为什么必须有 `\0`？→ 所有字符串函数靠它判断结束
- `char *s="hi"` 和 `char s[]="hi"` 区别？→ 前者指向只读区不能改；后者是数组能改
- 怎么正确比较两个字符串相等？→ `strcmp(a,b)==0`，不能用 `==`
- `strncpy` 最阴的坑？→ 可能不补 `\0`，目标要自己补结尾
- 统计单词为什么用状态机不用「数空格」？→ 连续/首尾空格会让空格计数法错

# 04 流程控制（大白话版）

> 来源：QQ `03.md`（if / switch / for）+ `04.md`（while / do-while / break / continue / goto）
> 配套详版：[02-基础语法.md](../02-基础语法.md)（运算符/优先级）

程序默认从上往下走；流程控制就是「**在哪儿分叉、在哪儿绕圈**」。

---

## 1. 分支：if / else if / else

```c
if (score >= 90)      printf("A\n");
else if (score >= 80) printf("B\n");
else if (score >= 60) printf("D\n");
else                  printf("不及格\n");
```

**铁律**：`else` 永远跟**最近的那个 `if`** 配对（就近原则）。多层嵌套时**一定加花括号**，否则容易写出「悬空 else」的坑。

课堂真题：成绩分档、判断奇偶、找最大数，全是这套路。

---

## 2. switch：多选一（比一堆 if-else 清爽）

```c
switch (number) {
  case 1: printf("one\n");   break;
  case 2: printf("two\n");   break;
  default: printf("other\n"); break;
}
```

**两个必考点**：
- **每个 case 末尾要 `break`**，否则会「穿透」继续执行下一个 case（有时故意利用穿透，但要在注释里写清楚）。
- `switch` 的 `case` 只能是**整型/字符常量**，不能是区间（`case x>5:` 不行）也不能是浮点/字符串。

## 3. 循环三兄弟

| 循环 | 特点 | 适用 |
|------|------|------|
| `for (init; cond; update)` | 初始化/条件/自增写一起 | **已知次数**的遍历 |
| `while (cond)` | 先判条件再执行 | **未知次数**、条件驱动 |
| `do { } while (cond);` | **先执行一次**再判条件 | 至少跑一次的菜单/输入 |

```c
for (int i = 0; i < 5; i++) printf("%d ", i);   // 0 1 2 3 4

int c = 0;
while (c < 5) { printf("%d ", c); c++; }          // 0 1 2 3 4

int x;
do { printf("至少进来一次\n"); } while (0);       // 一定执行一次
```

**for 三段式本质**：`init` 只跑一次；每轮先判 `cond`，真就跑循环体，再跑 `update`。`for(;;)` 是死循环（配 `break` 用）。

---

## 4. break / continue

- `break`：**立刻跳出整个循环**（或 switch）。
- `continue`：**跳过本次剩余、直接进入下一轮**。

```c
for (int i = 0; i < 10; i++) {
  if (i == 3) continue;   // 3 不打印
  if (i == 7) break;      // 到 7 整个循环停
  printf("%d ", i);        // 0 1 2 4 5 6
}
```

---

## 5. 循环嵌套

内外层各一个循环，常用于**二维数组、打印图形、矩阵**：

```c
for (int i = 0; i < 3; i++)
  for (int j = 0; j < 3; j++)
    printf("Row %d Col %d\n", i, j);
```

## 6. goto：能不用就不用

`goto label;` 直接跳到 `label:` 处。课堂笔记说「通常我们不认为这是好实践」，乱用会让流程乱成毛线球。
**唯一公认的好用处**：多层资源清理（比如打开多个文件，出错时统一 `goto cleanup` 释放）。日常写业务逻辑别碰。

```c
int count = 0;
start:
  if (count >= 5) goto end;
  printf("%d\n", count++);
  goto start;
end:
  printf("done\n");
```

## 7. 一张图：for 循环的一生

```
for ( i=0 ; i<5 ; i++ )
       │      │     │
       ▼      ▼     ▼(每轮末尾)
    只一次   每轮先判  判完再自增
       │      │
       ▼      ▼
    进循环 ──→ 条件真? ──是──▶ 循环体 ──▶ i++ ──┐
                  │                              │
                 否                              │
                  ▼                              │
                退出 ◄──────────────────────────┘
```

## 自测
- `switch` 的 `case` 能用 `x > 5` 这种区间吗？→ **不能**，只能是整型/字符常量
- 忘了写 `break` 会怎样？→ case 穿透，继续执行下一个 case
- `while` 和 `do-while` 最本质区别？→ do-while **至少执行一次**
- `break` vs `continue`？→ break 跳出整个循环；continue 跳到下一轮

# 08 结构体与联合体（大白话版）

> 来源：QQ `09.md`（结构体 / 枚举 / 共用体）+ `18(1).md`（结构体指针 / 链表 / 模拟多态）
> 结构体指针（传参 / 链表 / 多态）的深入写法见 `09-指针通俗精讲.md` 第 11 节，本篇补齐「定义与组合」部分。

数组要求元素**同类型**；现实数据往往是「用户名 + 年龄 + 身高」这种**不同类型混在一起**——结构体 `struct` 就是干这个的。

---

## 1. 定义与声明

```c
struct Student {
  char name[50];
  int age;
  float height;
};
struct Student stu1;                 // 定义后声明
struct Student stu2 = {"jim", 20, 1.83};  // 声明时初始化
// 访问用 `.`
printf("%s %d %.2f\n", stu2.name, stu2.age, stu2.height);
```

- 访问成员用 `.`（点）：`stu.age = 22;`
- 改字符数组成员：`stu.name[1] = 'i';` 或 `strcpy(stu.name, "tom");`（别用 `=` 整体赋值字符串）

---

## 2. 嵌套结构体

结构体里可以套结构体，像俄罗斯套娃：

```c
struct Address { char province[30]; char city[30]; };
struct Person {
  char name[50];
  int age;
  struct Address addr;     // 套一个地址
};
struct Person p = {"张三", 50, {"湖北", "武汉"}};
printf("%s %s\n", p.addr.province, p.addr.city);
```

---

## 3. 动态分配的结构体（堆上）

```c
struct Student *s = (struct Student *)malloc(sizeof(struct Student));
if (s != NULL) {
  strcpy(s->name, "jim");   // 指针用 -> 访问成员
  s->age = 18;
  free(s);                  // 用完还
}
```

`->` 是「指针访问成员」的语法糖：`p->age` ≡ `(*p).age`。因为 `.` 优先级高于 `*`，不括号会错，所以 `p->age` 顺手得多。

---

## 4. 与函数结合

- 传值：`void print_student(struct Student s)` —— 会**复制整个结构体**，字段多时费。
- 传指针：`void print(const struct Student *p)` —— 只传 4/8 字节，加 `const` 表「只读」。
- 工厂函数：返回结构体本身 `struct Student create_student(...)`。

```c
struct Student create_student(char name[], int age, float h) {
  struct Student s;
  strcpy(s.name, name); s.age = age; s.height = h;
  return s;
}
```

## 5. 匿名结构体 / 字面量清零

```c
struct Person {
  char name[50];
  struct { int day; int month; int year; } birthday;  // 匿名，直接 p.birthday.day 访问
};
// 清零三种写法：
memset(&student, 0, sizeof(student));   // ① memset 整块清 0
student = (struct Student){0};           // ② C99 字面量整体清零
struct Student zero = {0}; student = zero;  // ③ 先做一个全 0 再赋值
```

**坑**：`memset` 按字节填 0，对 int/char 没问题，但对 `float` 填 0.0 也 OK（IEEE754 全 0 就是 0.0），对指针填 NULL 也 OK；**别用 memset 给 int 填别的数字**（会按字节填）。

## 6. 枚举 enum：给魔法数字起名字

```c
enum Color { RED, GREEN, BLUE };   // 默认 0,1,2
enum WeekDay { MONDAY = 1, TUESDAY };  // 可指定，后面顺延
enum Color c = GREEN;

// 类型别名，少写 struct/enum
typedef enum { SMALL, MIDDLE, LARGE } Size;
// 当函数返回值，比返回 0/1 可读
typedef enum { SUCCESS, FAIL } Result;
Result check(int a, int b) { return a == b ? SUCCESS : FAIL; }
```

**好处**：`switch(dir)` 里写 `case NORTH:` 比写 `case 0:` 可读性高十倍，也方便和函数指针配合做状态机（见 `09-指针通俗精讲` 第 10.5）。

## 7. 共用体 union：成员抢同一块内存

> 详细见 [01-数据类型与存储](01-数据类型与存储.md) 第 6 节。

`union` 所有成员**共用一块内存**，大小 = 最大成员。同一时刻只有一个有效，改一个其他失效。用于「同一份数据想用不同视角看」或省内存。

```c
union Data { int i; float f; char s[20]; };
union Data d;
d.i = 10;          // 现在按 int 看是 10
d.f = 1.23;        // 覆盖，按 float 看是 1.23
```

---

## 8. 结构体指针 → 链表 → 模拟多态（串起指针篇）

`struct` 里放一个「指向下一个同类节点的指针」，就串成**链表**——C 里所有动态数据结构（链表/树/图）的地基：

```c
typedef struct Node { int data; struct Node *next; } Node;
// node1.next = &node2; ... 顺着 next 遍历，到 NULL 收尾
```

把「函数指针当方法」塞进结构体，就能在 C 里**模拟面向对象/多态**（详见 `09-指针通俗精讲` 第 11.5：Animal 工厂 `animals[i].speek()` 同一个接口不同表现 = 多态；Task 工厂 `createTask` 返回 malloc 的结构体）。

## 自测
- 访问结构体成员哪两种符号？→ `.`（变量）和 `->`（指针），`p->x` ≡ `(*p).x`
- 传结构体给函数为什么常传指针？→ 省去整块复制，加 const 还表只读
- `union` 和 `struct` 本质区别？→ union 成员共用内存、同时只一个有效；struct 各占各的
- 为什么 `enum` 比裸 `0/1` 好？→ 可读性高、配 switch/函数指针清晰

# C语言

## 一、数据类型

### 1.整型

| 类型        | 字节（64 位 Linux） | 有符号范围     | 说明                     |
| :---------- | :-----------------: | :------------- | :----------------------- |
| `char`      |          1          | -128 ~ 127     | 本质是整数，存字符 ASCII |
| `short`     |          2          | -32768 ~ 32767 | 至少 2 字节              |
| `int`       |          4          | ±21 亿         | 依赖平台"自然大小"       |
| `long`      |          8          | ±9.22×10^18    | 标准下限"至少 4B"        |
| `long long` |          8          | ±9.22×10^18    | 标准下限"至少 8B"        |

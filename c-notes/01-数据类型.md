# C语言

## 一、数据类型

### 1.整型

| 类型        | 字节（64 位 Linux） | 有符号范围     | 说明                     |
| :---------- | :-----------------: | :------------- | :----------------------- |
| `char`      |          1          | -128 ~ 127     | 本质是整数，存字符 ASCII |
| `short`     |          2          | -32768 ~ 32767 | 至少 2 字节              |
| `int`       |          4          | ±21 亿         | 依赖平台"自然大小"       |
| `long`      |          8          | ±9.22×10^18    | 标准下限"至少 4B"        |
| `long long` |          8          | ±9.22×10^18    | 标准下限"至少 8B"        |

记忆锚点：**尺寸链只保证 `char ≤ short ≤ int ≤ long ≤ long long`**，具体宽度平台说了算。
选型标准三条：代码移植性、表达意图明确、配合库函数的 API。

### 2. 有符号与无符号

**结论**：signed 用**最高位当符号位**（0 正 1 负）；unsigned 没有符号位，全部位都算数值，范围翻倍。

| 1 字节 | 最小 | 最大 |
|--------|------|------|
| signed char | -128 | 127 |
| unsigned char | 0 | 255 |
| unsigned int（4B） | 0 | 42 亿 |

### 3. 补码：负数在内存里的真实样子

**两条规则**：
- 正数：直接用二进制表示
- 负数：**取绝对值的二进制 → 按位取反 → 加 1**

**实测验证**（gcc 6.3.0）：

```c
int c1 = -5;
int c2 = ~c1 + 1;      /* c2 = 5  —— 取反加一，负数变回正数 */
printf("%d %d", ~5 + 1, ~4);   /* 输出 -5 -5 */
```

三个必记结论（都实测过）：

| 表达式 | 结果 | 含义 |
|--------|------|------|
| `~5 + 1` | -5 | 想得到 -x，就 `~x + 1` |
| `~4` | -5 | `~x = -(x+1)`，比取反加一少一步 |
| `~(-5) + 1` | 5 | 对负数做同样操作，得到它的相反数 |

**溢出回绕**（补码的必然结果，实测）：

```c
char c = 127; c = c + 1;        /* c = -128，最大值+1 绕回最小值 */
unsigned char uc = 255; uc++;   /* uc = 0 */
unsigned int ui = 0; ui--;      /* ui = 4294967295（42亿-1），0 往下绕到最大 */
```

**无符号比较陷阱**（嵌入式面试经典，实测 `(-1 < 1u)` 得 **0**）：
int 的 -1 遇到 unsigned 会先转成无符号（变成 42 亿多），再比较 → 结果"错"。
循环写 `for (unsigned i = n-1; i >= 0; i--)` 永远退不出去，就是这个坑的变种。

### 4. 实型：float 与 double 的内部结构

**结论**：浮点数 = 符号位 + 指数位 + 尾数位，**大多数小数存不精确**。

| 类型 | 字节 | 结构 | 有效精度 |
|------|:---:|------|---------|
| float | 4 | 1 符号 + 8 指数 + 23 尾数 | 6~7 位十进制 |
| double | 8 | 1 符号 + 11 指数 + 52 尾数 | 15~16 位十进制 |
| long double | 12/16 | 平台实现 | 不低于 double |

（float.h 的 `FLT_DIG=6`、`DBL_DIG=15`，实测输出一致）

**为什么 0.1 + 0.2 != 0.3**（实测：差 5.55e-17）：

```c
printf("%d\n", 0.1 + 0.2 == 0.3);                    /* 0 —— 不相等！ */
printf("%.17g\n", 0.1 + 0.2 - 0.3);                   /* 5.55e-17，不是 0 */
int ok = fabs(0.1 + 0.2 - 0.3) <= 1e-9;               /* 1 —— 正确的比较方式 */
```

0.1 和 0.2 在二进制里都是**无限循环小数**（就像十进制的 1/3），存进有限位数只能截断，误差就此产生。

**float 装不下 0.1 的证据**（实测）：`float f = 0.1f;` 提升成 double 打印是 `0.10000000149011612`。

**规则**：浮点数**永远不要用 == 直接比**，用 `fabs(a - b) <= 容差`。

### 5. sizeof 与 size_t

**结论**：sizeof 返回 `size_t` 类型（本质是 `unsigned long` 之类的无符号整数），专用格式符 **`%zu`**。

```c
printf("%zu\n", sizeof(int));     /* 4 */
printf("%zu\n", sizeof(char));    /* 1 —— 唯一一个标准保证恒为 1 的类型 */
```

两个实测发现的坑：

- **`sizeof('a')` = 4 不是 1**：C 里字符字面量 `'a'` 的类型是 **int**（C++ 里才是 char，这是 C/C++ 面试对比题）
- **本机 MinGW 用 `%zu` 会报 warning**（"unknown conversion type 'z'"，msvcrt 老运行时的锅），但输出仍正确；Linux gcc 上干净无警告。**考试按 C99 标准答 `%zu`**

### 6. 构造类型一览（后面几讲展开，先混个脸熟）

| 类型 | 特点 | 一句话 |
|------|------|--------|
| 数组 | 固定大小的连续内存块 | 同类型数据的排队 |
| 结构体 struct | 自定义类型，成员**类型可不同** | 把一个人的学号和姓名打包 |
| 共用体 union | 所有成员**共用一块内存**（大小=最大成员） | 同一块内存的多种解释 |
| 枚举 enum | 一组命名的整数**常量** | 给 0,1,2 起名字 |
| 指针 | 保存内存地址，大小看平台（64 位=8 字节） | 地址本身也是数据 |

**嵌入式视角**：union 的"同一块内存多种解释"就是寄存器位域操作的原型；结构体+指针是驱动里设备描述表的标准形态。

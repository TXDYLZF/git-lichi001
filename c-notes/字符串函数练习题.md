## 三、编程题（动手写，gcc 实测通过标准）

**S1.（热身）** 输入一行字符串，输出它的长度和逆序后的内容。不许用 strrev（标准库没有）。
　　测试：输入 `abcdef` → 输出 `6` 和 `fedcba`。

**S2.（随堂任务变式）** 统计一行字符串中单词数量，但**单词定义升级**：只把"纯字母段"算单词（含数字或标点的段不算）。
　　测试：输入 `i have 2 cats and 1 dog` → 输出 `5`（i/have/cats/and/dog 计数；`2`、`1` 这种纯数字段不算）。
　　提示：在状态机基础上多加一个标志——段结束时检查这一段是否全为字母（可用 `isalpha()`）。

**S3.** 实现自己的 `int my_strcmp(const char *a, const char *b)`，不许调用 strcmp。
　　测试：my_strcmp("abc","abc")==0；my_strcmp("abc","abd")<0；my_strcmp("abc","ab")>0。

**S4.** 输入一行，把每个单词**倒序输出单词序列**（单词顺序反过来，单词本身不反）。
　　测试：输入 `hello c world` → 输出 `world c hello`。
　　提示：可以 strtok 切分存入指针数组，再倒着 puts；进阶：不许额外数组，用 strrchr 从尾往前找空格。

**S5.（综合，嵌入式风）** 实现一个简单的"命令解析器"：读一行如 `set temp 25`，用 strtok 按**空格**切分，第一段是命令名，后面是参数。实现 `set`（打印 `SET: name=temp`）和 `get`（打印 `GET: name`）两个命令，未知命令打印 `UNKNOWN`。
　　测试：`set temp 25` → `SET: temp=25`；`get temp` → `GET: temp`；`reboot` → `UNKNOWN`。

# 答案与解析

**#52 → B**。strlen=3 不含 '\0'；sizeof=4 是数组总大小（含 '\0'）。

**#53 → C**。== 比地址；= 是赋值（还恒真）；strcmp 比内容。

**#54 → C**。strncpy 拷了 5 字节恰好填满 buf[6] 前 5 位，src 长度 ≥ n 时不写 '\0'，printf 会继续读越界内存。

**#55 → B**。strncat 追加 n 字符后总补 '\0'。strncpy 恰恰不保证补。这是 strncpy/strncat 的经典对比考点。

**#56 → A**。strchr 找第一个。找最后一个用 strrchr。

**#57 → B**。strchr 只找单个字符，strstr 找子串。

**#58 → B**。snprintf 返回"本应写入"的长度 12，但 buf 只装下 7 字符+'\0'。`n >= sizeof buf` 即为截断信号。

**#59 → D**。strtok 用静态指针记状态，非线程安全；多线程用 strtok_r。

**#60 → B**。strlen 返回 size_t（无符号），小减大回绕成巨大正数，< 0 永远为假。应写 `strlen(a) < strlen(b)`。

**#61 → B**。fgets 保留换行符，标准惯用法 `line[strcspn(line, "\n")] = '\0';` 一行解决。

**#62**。① `buf[4]` 只有 4 字节，"hello" 要 6 字节，strcpy 直接栈溢出；② 即使没溢出，strcat 再追加 " world" 更放不下；③（附加）`char *p = "hello"` 指向只读区，虽然这里只读不写没事，但同样要警惕。正确：buf 至少 `strlen(p)+strlen(" world")+1` = 12 字节。

**#63**。strtok 按分隔符把整串切成若干段依次返回（破坏原串、记住上次位置）；strchr/strstr 只做一次查找、返回位置指针、不修改原串。副作用：strtok 用静态变量，不可重入、非线程安全。

**S1 参考实现（实测通过）**：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[128];
    if (fgets(s, sizeof s, stdin) == NULL) return 1;
    s[strcspn(s, "\n")] = '\0';
    printf("%d\n", (int)strlen(s));
    int i = 0, j = (int)strlen(s) - 1;      /* 双指针原地交换 */
    while (i < j) {
        char t = s[i]; s[i] = s[j]; s[j] = t;
        i++; j--;
    }
    printf("%s\n", s);
    return 0;
}
```

**S2 参考实现（实测通过）**：

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int count_alpha_words(const char *s) {
    int count = 0, in_word = 0, all_alpha = 0;
    while (1) {
        if (isalpha((unsigned char)*s)) {
            if (!in_word) { in_word = 1; all_alpha = 1; } /* 新段开始 */
        } else {
            if (in_word && all_alpha) count++;  /* 段结束且全为字母才计数 */
            in_word = 0; all_alpha = 0;
            if (*s == '\0') break;
        }
        s++;
    }
    return count;
}

int main(void) {
    char line[256];
    if (fgets(line, sizeof line, stdin) == NULL) return 1;
    line[strcspn(line, "\n")] = '\0';
    printf("%d\n", count_alpha_words(line));
    return 0;
}
```

思路：在 §9 状态机上多加一个 `all_alpha` 标志——"2" 这种数字段也进入 in_word，但段结束时检查全为字母才 count++。

**S3 参考实现（实测通过）**：

```c
int my_strcmp(const char *a, const char *b) {
    while (*a && *a == *b) {   /* 还没结束且当前字符相等就继续 */
        a++; b++;
    }
    return (int)(unsigned char)*a - (int)(unsigned char)*b;
    /* 出循环时：要么 *a=='\0'，要么第一次不等的位置。差值符号即结果 */
}
```

**S4 参考实现（strtok 版，实测通过）**：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char line[256];
    if (fgets(line, sizeof line, stdin) == NULL) return 1;
    line[strcspn(line, "\n")] = '\0';

    char *words[64];
    int n = 0;
    for (char *t = strtok(line, " \t"); t && n < 64; t = strtok(NULL, " \t"))
        words[n++] = t;

    for (int i = n - 1; i >= 0; i--)
        printf("%s%c", words[i], i ? ' ' : '\n');
    return 0;
}
```

**S5 参考实现（实测通过）**：

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char line[256];
    if (fgets(line, sizeof line, stdin) == NULL) return 1;
    line[strcspn(line, "\n")] = '\0';

    char *cmd  = strtok(line, " ");
    char *arg1 = strtok(NULL, " ");
    char *arg2 = strtok(NULL, " ");

    if (cmd == NULL)                    { puts("UNKNOWN"); }
    else if (strcmp(cmd, "set") == 0)   { printf("SET: %s=%s\n", arg1, arg2); }
    else if (strcmp(cmd, "get") == 0)   { printf("GET: %s\n", arg1); }
    else                                { puts("UNKNOWN"); }
    return 0;
}
```

这正是嵌入式中串口命令行（CLI shell）的雏形——rtos 上常见的 finsh/msh 就是这个结构再加一张命令表。

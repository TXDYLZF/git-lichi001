## 0. 先解决一个痛点：没有指针，函数改不了外面的东西

想写个函数交换两个数：

```c
void swap(int x, int y){ int t=x; x=y; y=t; }
int main(){ int a=1,b=2; swap(a,b); }
```

跑完 `a`、`b` 还是 1、2。因为 C 是 **值传递**——函数拿到的是 `a`、`b` 的**复印件**，你在复印件上改，原件纹丝不动。

**怎么办？** 把 `a`、`b` 的**柜子编号（地址）**告诉函数，让它去原件上改。这就是指针登场的理由。

---

## 1. 指针到底是什么？（储物柜类比）

把内存想成**一排带编号的储物柜**：

- 普通变量 `int a=10;` → 你占了一个柜子（编号 `0x1000`），里面放了 10。
- 指针变量 `int *p;` → 它也是一个柜子（编号 `0x2000`），但里面**不放数据，放的是另一个柜子的编号**（`0x1000`）。

所以：**指针 = 存"别的柜子编号"的柜子**。你拿着 `p` 里的编号，去找到那个柜子再读/写，这就是"间接访问"。

```
   变量 a                指针 p
 ┌───────────┐        ┌───────────┐
 │ 地址 0x1000│        │ 地址 0x2000│
 │  值 = 10   │        │ 存 = 0x1000│
 └───────────┘        └─────┬─────┘
                             │  p 里装的是 a 的地址（指向 a）
                             └──────────────►
```

> `int a=10;  int *p=&a;  // *p 读出 10`

---

## 2. 两个符号：& 和 *（一对互逆操作）

- `&a` = "查 a 的柜子编号" → **取地址**。`int *p = &a;` 就是：把 a 的编号存进 p。
- `*p` = "按 p 里存的编号，打开那个柜子" → **解引用**，可读可写。
- 互逆：`*&a` 就是"打开 a 的柜子" = a；`&*p` = p。
- 同一个 `*` 有两个身份：**声明时**只说明"这是指针"，**表达式里**才真去开柜子。所以 `int *p, q;` 里 **q 是普通 int**，不是指针——这是高频坑。

---

## 3. 指针为什么必须有"类型"？（最易被忽略，必考）

指针里存的只是一串地址数字，编译器怎么知道该读几个字节、往哪走？**靠类型。**

- `int*`：认为指向 int（4 字节）
- `double*`：认为指向 double（8 字节）

这决定两件大事：
1. 解引用一次读几字节（`*p` 一次拿 4 还是 8）
2. **`p+1` 走几字节**——不是地址 +1，是地址 + `sizeof(类型)`

```
 int 数组（每个格 4 字节）
 ┌────────┬────────┬────────┐
 │0x1000  │0x1004  │0x1008  │
 │  a[0]  │  a[1]  │  a[2]  │
 └───┬────┴───┬────┴────────┘
     │p       │p+1
  p+1 不是地址+1，而是地址 + sizeof(int) = +4
  double* 走 8 字节，char* 走 1 字节
```

**口诀：类型即刻度。**

---

## 4. 指针和数组，本是一家

- 数组名 `a` 在大多数情况下就是**首元素地址**（= `&a[0]`），所以 `a[i]` 本质就是 `*(a+i)`：从首地址走 i 步，开那个柜子。
- 反过来，指针也能当数组用：`int *p=a; p[3]` 和 `a[3]` 完全一样。
- **关键区别**：数组名 `a` 是**常量**（首地址写死），不能 `a++`；想移动就用另一个指针 `int *p=a; p++;`。

---

## 5. 数组传给函数为什么会"缩水"？

```c
void f(int a[]){ printf("%zu\n", sizeof(a)); }  // 拿到的是指针大小，不是数组大小
```

因为 C 不允许整数组按值传参，传进去的其实是首地址，形参本质成了 `int*`（`f(int a[])` 和 `f(int *a)` 完全等价）。所以**数组长度必须单独传**：`f(a, n)`。

## 6. 字符串 = 字符数组，但两种写法天差地别

```c
char *s = "hello";   // s 指向只读区的字面量，不能改（改了段错误）
char  t[] = "hello"; // t 是栈上的数组，内容可以改
```

遍历字符串靠 `'\0'` 收尾：`while(*p) putchar(*p++);`

## 7. 指针当函数参数 = 传址调用（解决第 0 节的痛点）

```c
void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }
swap(&a, &b);   // 把地址传进去，函数直接改原件
```

想让函数**返回多个值**，也用指针"带出来"：

```c
void divmod(int a, int b, int *q, int *r){ *q = a/b; *r = a%b; }
```

## 8. 动态内存 malloc / free（借来的内存要还）

栈上的变量函数一返回就消失；想运行时才定大小，用 `malloc` 从**堆**借：

```c
int *p = malloc(5 * sizeof(int));
if (p == NULL) { /* 申请失败，别用 */ }
p[3] = 30;
free(p);
p = NULL;        // 用完归还，立刻置 NULL 防悬空
```

---

## 9. 三种危险指针（考试重灾区）

| 类型 | 怎么来的 | 后果 |
|------|---------|------|
| **野指针** | 没初始化就 `*p=5` | 写进随机地址，段错误 |
| **悬空指针** | `free` 后没置 NULL 还在用 | 内存已归还，未定义行为 |
| **NULL 指针** | 初始化/释放后置 NULL | 也崩，但**能 `if(p==NULL)` 防御** |

**铁律**：定义即初始化（暂不指就 `=NULL`）；`free` 后立刻 `p=NULL`；用前判空。

## 10. 函数指针（遥控器上存的是"操作编号"）

普通变量存数据，函数指针存的是**另一个函数的入口地址**。所以你能用一个变量在运行时切换"当前用哪个函数"。

我们写了三个 demo（在 `D:\学习工作台\草稿箱\`）：

- `fp_calc.c`：函数指针数组做四则运算分发表（免 `if-else` 链）
- `fp_qsort.c`：把"比较规则"当参数传给 qsort（回调）

## 11. 二级指针 int**（指针的指针）

`pp` 里存的是某个 `int*` 的地址。用途：在函数里**改一个一级指针本身**（比如让函数内部 `malloc` 出内存并让外面的指针指向它，必须传 `int**`）——因为值传递改不了指针变量本身，传它的地址才行。

```c
int a = 5;
int *p = &a;
int **pp = &p;
printf("%d\n", **pp);   // 5：解两次引用
```

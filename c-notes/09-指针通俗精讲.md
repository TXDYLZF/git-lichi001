## 0. 先解决一个痛点：没有指针，函数改不了外面的东西

想写个函数交换两个数：

```c
void swap(int x, int y){ int t=x; x=y; y=t; }
int main(){ int a=1,b=2; swap(a,b); }
```

跑完 `a`、`b` 还是 1、2。因为 C 是 **值传递**——函数拿到的是 `a`、`b` 的**复印件**，你在复印件上改，原件纹丝不动。

**怎么办？** 把 `a`、`b` 的**柜子编号（地址）**告诉函数，让它去原件上改。这就是指针登场的理由。

---

## 1. 指针到底是什么？（储物柜类比）

把内存想成**一排带编号的储物柜**：

- 普通变量 `int a=10;` → 你占了一个柜子（编号 `0x1000`），里面放了 10。
- 指针变量 `int *p;` → 它也是一个柜子（编号 `0x2000`），但里面**不放数据，放的是另一个柜子的编号**（`0x1000`）。

所以：**指针 = 存"别的柜子编号"的柜子**。你拿着 `p` 里的编号，去找到那个柜子再读/写，这就是"间接访问"。

```
   变量 a                指针 p
 ┌───────────┐        ┌───────────┐
 │ 地址 0x1000│        │ 地址 0x2000│
 │  值 = 10   │        │ 存 = 0x1000│
 └───────────┘        └─────┬─────┘
                             │  p 里装的是 a 的地址（指向 a）
                             └──────────────►
```

> `int a=10;  int *p=&a;  // *p 读出 10`

---

## 2. 两个符号：& 和 *（一对互逆操作）

- `&a` = "查 a 的柜子编号" → **取地址**。`int *p = &a;` 就是：把 a 的编号存进 p。
- `*p` = "按 p 里存的编号，打开那个柜子" → **解引用**，可读可写。
- 互逆：`*&a` 就是"打开 a 的柜子" = a；`&*p` = p。
- 同一个 `*` 有两个身份：**声明时**只说明"这是指针"，**表达式里**才真去开柜子。所以 `int *p, q;` 里 **q 是普通 int**，不是指针——这是高频坑。

---

## 3. 指针为什么必须有"类型"？（最易被忽略，必考）

指针里存的只是一串地址数字，编译器怎么知道该读几个字节、往哪走？**靠类型。**

- `int*`：认为指向 int（4 字节）
- `double*`：认为指向 double（8 字节）

这决定两件大事：
1. 解引用一次读几字节（`*p` 一次拿 4 还是 8）
2. **`p+1` 走几字节**——不是地址 +1，是地址 + `sizeof(类型)`

```
 int 数组（每个格 4 字节）
 ┌────────┬────────┬────────┐
 │0x1000  │0x1004  │0x1008  │
 │  a[0]  │  a[1]  │  a[2]  │
 └───┬────┴───┬────┴────────┘
     │p       │p+1
  p+1 不是地址+1，而是地址 + sizeof(int) = +4
  double* 走 8 字节，char* 走 1 字节
```

**口诀：类型即刻度。**

---

## 4. 指针和数组，本是一家

- 数组名 `a` 在大多数情况下就是**首元素地址**（= `&a[0]`），所以 `a[i]` 本质就是 `*(a+i)`：从首地址走 i 步，开那个柜子。
- 反过来，指针也能当数组用：`int *p=a; p[3]` 和 `a[3]` 完全一样。
- **关键区别**：数组名 `a` 是**常量**（首地址写死），不能 `a++`；想移动就用另一个指针 `int *p=a; p++;`。

---

## 5. 数组传给函数为什么会"缩水"？

```c
void f(int a[]){ printf("%zu\n", sizeof(a)); }  // 拿到的是指针大小，不是数组大小
```

因为 C 不允许整数组按值传参，传进去的其实是首地址，形参本质成了 `int*`（`f(int a[])` 和 `f(int *a)` 完全等价）。所以**数组长度必须单独传**：`f(a, n)`。

---

## 6. 字符串 = 字符数组，但两种写法天差地别

```c
char *s = "hello";   // s 指向只读区的字面量，不能改（改了段错误）
char  t[] = "hello"; // t 是栈上的数组，内容可以改
```

遍历字符串靠 `'\0'` 收尾：`while(*p) putchar(*p++);`

---

## 7. 指针当函数参数 = 传址调用（解决第 0 节的痛点）

```c
void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }
swap(&a, &b);   // 把地址传进去，函数直接改原件
```

想让函数**返回多个值**，也用指针"带出来"：

```c
void divmod(int a, int b, int *q, int *r){ *q = a/b; *r = a%b; }
```

---

## 8. 动态内存 malloc / free（借来的内存要还）

栈上的变量函数一返回就消失；想运行时才定大小，用 `malloc` 从**堆**借：

```c
int *p = malloc(5 * sizeof(int));
if (p == NULL) { /* 申请失败，别用 */ }
p[3] = 30;
free(p);
p = NULL;        // 用完归还，立刻置 NULL 防悬空
```

---

## 9. 三种危险指针（考试重灾区）

| 类型 | 怎么来的 | 后果 |
|------|---------|------|
| **野指针** | 没初始化就 `*p=5` | 写进随机地址，段错误 |
| **悬空指针** | `free` 后没置 NULL 还在用 | 内存已归还，未定义行为 |
| **NULL 指针** | 初始化/释放后置 NULL | 也崩，但**能 `if(p==NULL)` 防御** |

**铁律**：定义即初始化（暂不指就 `=NULL`）；`free` 后立刻 `p=NULL`；用前判空。

> ⚠️ 记牢：本节说的"悬空"是**返回局部变量的指针**——函数一返回，那个柜子就回收了，里面的编号作废。第 10.7 和 11 节会看到：返回"函数指针（函数入口地址）"是安全的，因为函数代码一直在，不在栈上。

## 10. 函数指针（遥控器上存的是"操作编号"）

普通变量存数据，**函数指针存的是另一个函数的入口地址**。形象点：普通变量柜子里放的是"东西"，函数指针柜子里放的是"一封操作指令的地址"——你按柜子里的地址，去执行那个函数。

函数指针的三大价值（课堂笔记原话）：**动态调用、回调、模拟多态**。

### 10.1 声明和初始化

```c
int add(int a, int b){ return a + b; }

int main(){
  int (*func_ptr)(int, int) = add;   // func_ptr 指向 add
  int result = func_ptr(1, 2);        // 像普通函数一样调用，得到 3
  printf("%d\n", result);
}
```

**白话**：`int (*func_ptr)(int,int)` 读作"func_ptr 是个指针，指向『返回 int、收两个 int』的函数"。`func_ptr = add;` 不用写 `&add`——**函数名本身就是它的入口地址**。

### 10.2 用 typedef 起短名（必学，否则又长又丑）

```c
typedef int (*MathFunc)(int, int);   // 给"函数指针类型"起个短名 MathFunc

int multiply(int a, int b){ return a * b; }

int main(){
  MathFunc func_ptr = multiply;       // 现在声明清爽多了
  printf("3*5=%d\n", func_ptr(3, 5)); // 15
}
```

**为什么**：原写法 `int (*func_ptr)(int,int)` 每次都要写一长串，容易写错。typedef 后当普通类型用，声明变量 `MathFunc x;` 一眼就懂。

### 10.3 动态调用：同一个变量，运行时换算法

```c
typedef int (*BinaryOperation)(int, int);

int add(int a, int b){ return a + b; }
int sub(int a, int b){ return a - b; }
int multiply(int a, int b){ return a * b; }

void applyOperation(int a, int b, BinaryOperation op){
  printf("result: %d\n", op(a, b));   // op 当前指向谁就调谁
}

int main(){
  applyOperation(2, 3, add);       // result: 5
  applyOperation(2, 3, multiply);  // result: 6
  applyOperation(5, 3, sub);       // result: 2
}
```

**白话**：`applyOperation` 不知道具体算什么，它只负责"拿 a、b 调你给的 op"。你传 add 就加、传 multiply 就乘——**一份调用代码，算什么由调用方决定**。这就是"回调"。

### 10.4 自写排序：比较规则也当参数传（回调的威力）

```c
int compare_asc(int a, int b){ return a - b; }   // 升序：前减后
int compare_desc(int a, int b){ return b - a; }  // 降序：后减前

void sort(int *array, int size, int (*compare)(int, int)){
  for (int i = 0; i < size; i++)
    for (int j = 0; j < size - i - 1; j++)
      if (compare(array[j], array[j+1]) > 0){    // 怎么比由 compare 决定
        int temp = array[j];
        array[j] = array[j+1];
        array[j+1] = temp;
      }
}

int main(){
  int arr[] = {5, 4, 8, 1, 6};
  sort(arr, 5, compare_desc);   // 传降序比较函数
  for (int i = 0; i < 5; i++) printf("%d ", arr[i]);  // 8 6 5 4 1
}
```

**白话**：排序算法（冒泡）固定不变，**唯独"谁大谁小"的判断交给你**。传 `compare_asc` 升序、传 `compare_desc` 降序——这就是回调最经典的用法（标准库 `qsort` 也是这个思路，见草稿箱 `fp_qsort.c`）。

### 10.5 状态机：函数指针当"当前状态"存（嵌入式高频）

```c
typedef void (*StateFunc)(void);

void state_off(void);
void state_on(void);

static StateFunc current_state = state_off;  // 当前状态 = 关灯函数

void state_off(void){ printf("灯关闭\n"); current_state = state_on; }
void state_on(void){  printf("灯打开\n"); current_state = state_off; }

int main(){
  for (int i = 0; i < 3; i++) current_state();  // 每次调用后，状态自己跳下一个
}
// 输出：灯关闭 / 灯打开 / 灯关闭
```

**白话**：`current_state` 这个柜子里存的是"现在该执行哪个状态函数"。调用它，函数内部自己把 `current_state` 改成下一个——**状态切换的逻辑分散在每个状态里**，主循环只管"按当前状态执行"。
**嵌入式关联**：裸机/RTOS 里的中断处理、协议解析、菜单导航全是这种"函数指针跳转表 / 状态机"，比一长串 `switch-case` 更省、更易扩展。

### 10.6 函数指针做结构体成员（C 里模拟"多态"）

```c
typedef struct {
  double (*calculate_area)(float, float);
} Shape;

double circle_area(float pi, float r){ return pi * r * r; }
double rectangle_area(float w, float h){ return w * h; }

int main(){
  Shape circle = { circle_area };
  Shape rectangle = { rectangle_area };
  printf("circle: %.2f\n",    circle.calculate_area(3.14, 5));   // π·r²
  printf("rectangle: %.2f\n", rectangle.calculate_area(4, 5));  // w·h
}
```

**白话**：结构体里放一个"方法指针"。不同的 Shape 装不同的面积算法，**调用 `xxx.calculate_area(...)` 时表现不同**——这就是课堂说的"在面向对象编程中模拟多态"。C 没有 class，但函数指针让结构体拥有了"自己的行为"。

### 10.7 从函数返回指针（返回的是"函数"，不是局部变量）

```c
typedef int (*BinaryOperation)(int, int);

BinaryOperation getOperation(char op){
  if (op == '+')      return add;       // 返回 add 的入口地址
  else if (op == '-') return sub;
  else if (op == '*') return multiply;
  else                return NULL;       // 没有匹配的，返回 NULL 防御
}

int main(){
  BinaryOperation op = getOperation('+');
  printf("result:%d\n", op(2, 3));   // 5
  op = getOperation('-');
  printf("result:%d\n", op(12, 3));  // 9
}
```

**白话**：函数返回的是**另一个函数的入口地址**（全局代码，永远有效），所以安全。注意区分：第 9 节说的"悬空"是返回**局部变量的指针**（栈上柜子已回收）；这里返回的是**函数名本身**（代码段不在栈上），没问题。返回后记得 `if(op==NULL)` 判空再调用。

### 10.8 三个常见错误（考试/作业重灾区）

```c
// ① 类型不匹配：函数指针签名必须和指向的函数完全一致
void func(int a){ /* ... */ }
int main(){
  void (*func_ptr)(char) = func;   // ❌ func 收 int，指针却声明收 char，参数类型不符
}

// ② 未初始化就调用：野函数指针
int (*func_ptr)(int,int);
func_ptr(1,2);                     // ❌ 没指向任何函数，崩溃

// ③ 错误调用：* 优先级低于 ()
int (*func_ptr)(int,int) = add;
int result = *func_ptr(1,2);      // ❌ 被解析成 *(func_ptr(1,2))，先调用再解引用，类型错
// 正确写法：func_ptr(1,2)  或  (*func_ptr)(1,2)   ← 给 * 加括号才对
```

**口诀**：函数指针调用直接写 `func_ptr(1,2)` 最省心；要加 `*` 就必须 `(*func_ptr)(1,2)` 把括号包住。

## 11. 结构体指针（把"结构体柜子"的编号存起来）

结构体也是变量，也占柜子。结构体指针 = 存"结构体柜子编号"的指针。

### 11.1 两种初始化：静态取地址 / 动态 malloc

```c
typedef struct {
  int id;
  char name[50];
} Person;

int main(){
  // 静态：直接取已有结构体的地址
  Person person = {1, "jim"};
  Person *personPtr = &person;          // personPtr 指向 person

  // 动态：从堆上现借一个
  Person *dynamicPerson = (Person *)malloc(sizeof(Person));
  if (dynamicPerson == NULL){           // 申请失败必须判空，否则后面崩
    printf("memory fail\n");
    exit(1);
  }
  dynamicPerson->id = 2;
  strcpy(dynamicPerson->name, "tom");

  free(dynamicPerson);                  // 用完归还
  dynamicPerson = NULL;                 // 立刻置 NULL 防悬空
}
```

**白话**：`->` 是"指针访问成员"的语法糖——`p->id` 完全等价于 `(*p).id`（先开柜子再取成员）。因为 `.` 优先级高于 `*`，`*p.id` 会错，所以要么写 `(*p).id`，要么写 `p->id`（后者顺手得多）。

### 11.2 传结构体指针给函数（高效 + 能改原件）

```c
void printPersonInfo(const Person *p){        // const：我只看不改
  printf("id: %d, name: %s\n", p->id, p->name);
}
void updatePersonName(Person *p, const char *newName){
  strcpy(p->name, newName);                   // 传指针才能改原结构体的内容
}
```

**为什么传指针不传整个结构体**：传值会把整个结构体复印一份（字段多时很费），传指针只传 4/8 字节；加 `const` 告诉读代码的人"这个函数不会改它"，安全又清晰。

### 11.3 嵌套结构体指针 = 链表雏形（数据结构的地基）

```c
typedef struct Node {
  int data;
  struct Node *next;     // 自己指自己：指向下一个节点
} Node;

int main(){
  Node node1 = {1, NULL};
  Node node2 = {2, NULL};
  Node node3 = {3, NULL};
  node1.next = &node2;   // node1 的 next 指向 node2
  node2.next = &node3;   // node2 的 next 指向 node3（node3.next 保持 NULL 收尾）

  Node *current = &node1;
  while (current != NULL){            // 走到 NULL 说明链表到头
    printf("value: %d\n", current->data);
    current = current->next;          // 顺着 next 跳到下一个
  }
}
// 输出：value: 1 / value: 2 / value: 3
```

**白话**：每个节点里除了数据，还存了"下一个节点的柜子编号"。串起来就是**链表**——C 里所有动态数据结构（链表、树、图）都是这个 `struct Node *next` 的变体。遍历时务必靠末尾的 `NULL` 收尾，否则 `current = current->next` 会一直走下去成死循环。
**嵌入式关联**：内核、驱动里大量用"结构体里嵌结构体指针"把设备/节点串成链（如 Linux 的 `list_head` 双向链表），是必须吃透的套路。

### 11.4 动态数组中的结构体指针（指针数组 + 逐元素 malloc）

如果元素个数运行期才定、或每块要独立申请/释放，就用"**指针数组**"：每个元素是个 `Person*`，各自 `malloc` 出一块。

```c
typedef struct {
  int id;
  char name[50];
} Person;

int main(){
  int n = 3;
  Person *person[n];                 // 指针数组：每个元素是个 Person*（数组本身在栈上）

  for (int i = 0; i < n; i++){
    person[i] = (Person *)malloc(sizeof(Person));
    if (person[i] == NULL){          // 任意一次失败，要把前面已成功的回滚释放，否则泄漏
      printf("memory fail\n");
      for (int j = 0; j < i; j++) free(person[j]);
      exit(1);
    }
    person[i]->id = i + 1;
    sprintf(person[i]->name, "person%d", i + 1);   // id:1→person1 ……
  }

  for (int i = 0; i < n; i++)
    printf("id: %d, name: %s\n", person[i]->id, person[i]->name);

  for (int i = 0; i < n; i++) free(person[i]);     // 释放每个元素（person 数组在栈上，不用 free）
}
```

**白话**：这跟"一块连续的结构体数组 `Person arr[10]`"不同——这里是 **N 块各自独立的内存**，每块的地址收在 `person[i]` 里。好处是每块大小可不同、可单独增删；坏处是内存不连续、读写缓存不友好，且要**逐个 malloc / 逐个 free**。

**必记坑**：
1. 失败时**回滚释放已成功的部分**（循环 `free` 前 `i` 个），否则内存泄漏。
2. 最后 `free` 的是每个 `person[i]`，不是 `person` 这个数组本身（数组在栈上，函数返回自动回收）。
3. 若把 `person` 本身也放堆上（`Person **person = malloc(n*sizeof(Person*))`），那 `free(person)` 要在释放完所有 `person[i]` 之后最后做。

### 11.5 结构体指针"面向对象"：把函数指针当"方法"塞进结构体

C 没有 `class`，但"**数据 + 操作数据的函数指针**"打包进一个 struct，就有了"对象"的雏形——课堂笔记讲的就是这个思路。

#### 11.5.1 Calculator：属性 + 方法 打包

```c
typedef int (*Operation)(int, int);

typedef struct {
  int a;          // 属性
  int b;          // 属性
  Operation op;   // 方法：函数指针当"成员方法"
} Calculator;

int add(int a, int b){ return a + b; }

int main(){
  Calculator calc = {10, 5, add};   // calc 这个"对象"带了一个方法 op
  // 用法：printf("%d\n", calc.op(calc.a, calc.b));  ← 像调用对象的方法
}
```

**白话**：`a`、`b` 是属性，`op` 是方法。调用 `calc.op(calc.a, calc.b)` 就像面向对象的 `calc.run()`——数据和行为绑在一起。

#### 11.5.2 模拟多态：同一个接口，不同表现（Animal 工厂）

```c
typedef struct {
  char name[50];
  void (*speek)(void);   // "会叫"这个方法
} Animal;

void dogSpeek(){ printf("wawa!!\n"); }
void catSpeek(){ printf("mimi!!\n"); }

Animal createDog(void){
  Animal dog;
  strcpy(dog.name, "旺财");
  dog.speek = dogSpeek;     // dog 装的叫法是狗叫
  return dog;
}
Animal createCat(void){
  Animal cat;
  strcpy(cat.name, "咪咪");
  cat.speek = catSpeek;     // cat 装的叫法是猫叫
  return cat;
}

int main(){
  Animal animals[] = {createDog(), createCat()};
  int n = sizeof(animals) / sizeof(Animal);
  for (int i = 0; i < n; i++){
    printf("%s says: ", animals[i].name);
    animals[i].speek();     // 同一个接口，狗/猫表现不同 → 这就是多态
  }
}
// 输出：旺财 says: wawa!! / 咪咪 says: mimi!!
```

**白话**：所有 `Animal` 都有统一的 `speek()` 接口，但 dog 和 cat 实际调用的函数不同。上层只管 `animals[i].speek()`，不用关心是狗是猫——**这正是 C++ 虚函数表的底层原理**，C 用函数指针就能模拟。

#### 11.5.3 Task 工厂：malloc 返回带"行为"的结构体

```c
typedef struct {
  char taskName[50];
  void (*execute)(void);   // 任务要执行的函数
} Task;

void taskOne(void){ printf("executing task one\n"); }
void taskTwo(void){ printf("executing task two\n"); }

Task *createTask(const char *name, void (*func)(void)){
  Task *task = (Task *)malloc(sizeof(Task));
  strncpy(task->taskName, name, sizeof(task->taskName) - 1);  // -1 留 '\0' 位置
  task->execute = func;
  return task;             // 返回堆上结构体指针
}

int main(){
  Task *task1 = createTask("Task one", taskOne);
  Task *task2 = createTask("Task two", taskTwo);
  task1->execute();        // executing task one
  task2->execute();        // executing task two
  free(task1);             // 动态申请的要 free
  free(task2);
}
```

**白话**：这是"**工厂函数**"模式——`createTask` 负责 `malloc` 一块 `Task` 并初始化好，返回指针给调用者。调用者用 `->execute()` 触发任务。记住：凡是 `malloc` 出来的，用完必须 `free`，否则泄漏。`strncpy` 的 `-1` 是为了给字符串结尾的 `'\0'` 留位置，防止溢出。

## 12. 二级指针 int**（指针的指针）

`pp` 里存的是某个 `int*` 的地址。用途：在函数里**改一个一级指针本身**（比如让函数内部 `malloc` 出内存并让外面的指针指向它，必须传 `int**`）——因为值传递改不了指针变量本身，传它的地址才行。

```c
int a = 5;
int *p = &a;
int **pp = &p;
printf("%d\n", **pp);   // 5：解两次引用
```

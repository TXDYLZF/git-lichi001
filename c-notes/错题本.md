### 变量与数据类型（4 条）

#### 1. 隐式转换的截断不是四舍五入 [2026-09-14]

**踩的坑**：`d = a + c`（a=1, c=1.25）得 2，不是 2.25。

**错因**：运算时就高不就低（int 提升为 double，得 2.25），赋值时向零截断（2.25→2）。2.75 也变 2，不是四舍五入。

**复习提示**：转换有两个独立时机——运算中提升、赋值时截断。自检：`float e = 5/2;` 得 2.00（整数除法在赋值前就把精度丢了，坑在除法不在转换）。

#### 2. 【练习】int a; 定义即分配内存 [2026-09-14]

**要点**：定义会分配内存；声明（`extern int a;`）不分配。

**复习提示**：分界线只有一条——"是否分配内存"。定义全程序唯一，声明可以多处；函数原型也是声明。

#### 3. 【练习】float/double 位结构 [2026-09-14]

**要点**：float 1+8+23 位、精度 6~7 位十进制；double 1+11+52 位、精度 15~16 位。`float.h` 的 FLT_DIG=6、DBL_DIG=15。

**复习提示**：FLT_DIG 是"可靠的有效十进制位"，不是"小数点后 6 位"；0.1 进不了 23 位尾数才是浮点误差的根源。

#### 4. 【练习】~(-5)+1 等于几 [2026-09-14]

**要点**：负数按补码存：绝对值取反加一。~(-5)+1 = 5，同族 ~5+1 = -5。

**复习提示**：恒等式 `~x + 1 == -x` 一记全家通。补码的意义：让加法器顺带完成减法（嵌入式 CPU 没有独立减法器）。

### 输入输出（2 条）

#### 5. 输入流结束导致死循环 [2026-09-14]

**踩的坑**：写猜数字游戏时，输入耗尽后程序无限循环疯转。

**错因**：`scanf` 返回 EOF 时进错误分支 `continue`，但缓冲区状态没变，一直转。

**正确思路**：错误分支里要检查 `feof(stdin)`，处理"输入流结束了"这种情况。

**教训**：**写任何读输入的循环都要问一句——输入流没了会怎样？**

**复习提示（09-14 每日整理）**：`scanf` 返回值是三态——成功读取的个数 / 0 / EOF(-1)。更稳的写法是把 `while (scanf("%d", &n) == 1)` 直接当循环条件，读不到就自然退出，不用事后查 feof（本机 gcc 实测：空输入下 `!=1 + continue` 版本 timeout 杀不掉在疯转，返回值版本立即退出）。嵌入式同理：轮询串口、传感器的循环，动笔前先回答"外设永远不出数据了会怎样"。

#### 6. scanf 的 %c 会吃掉换行符 [2026-09-14]

**踩的坑**：`scanf("%d")` 之后接 `scanf("%c")`，输入的字符读不到，读到的是换行符（ASCII 10）。

**错因**：`%d` 停在换行符前，`%c` 不跳过空白。

**正确思路**：`scanf(" %c")` 前面加一个空格。

**复习提示**：`%c` 是唯一不跳过前导空白的转换符；`%` 前那个空格的含义就是"跳过所有空白"（空格 / Tab / 换行）。

### 数组与函数（1 条）

#### 7. 函数定义、数组传参与 double 输入格式符 [2026-09-16]

**踩的坑**：
1. 函数定义写成 `int(double score[])` —— 没有函数名，编译直接报错。
2. `printf` 里 `"i+1\n"` 把 `\n` 写到字符串外面，语法错误。
3. `scanf("%d", &scores[i])` 读 `double` 数组 —— `%d` 对应 `int`，应该用 `%lf`。
4. 输入负数时直接 `return 1`，把"结束输入"当成"退出程序"，导致后面没法再统计。
5. 函数里循环固定到 40，没有传入实际人数，也没算平均分。

**正确思路**：
- 函数签名：`int countAboveAverage(double score[], int n)`（数组 + 实际长度）
- 输入：临时变量 `x`，负数 break；正数存入 `scores[n]`，然后 `n++`
- 统计：先求和算平均分，再遍历统计 `> avg` 的个数
- 返回：函数返回值是人数；平均分可以用指针带出来

**教训**：**数组传函数一定要传"实际长度 n"**，不能只传数组；`scanf` 格式符和变量类型必须配对；遇到"输入结束"要先 `break`，不要 `return`。

**复习提示**：`double` 用 `scanf` 时格式符是 `%lf`，`printf` 时用 `%f`（`printf` 里 `%f` 同时兼容 float/double，因为 float 会默认提升为 double）。函数想返回多个结果，C 标准做法是用指针参数。

### 流程控制（2 条）

#### 8. 【练习】if-else if 顺序 [2026-09-14]

**要点**：if-else if 从上往下命中即止：85 先撞上 `>=60` 为真输出 C，后面不再看。区间判断必须从大到小写（90→80→60）。

**复习提示**：else if 的语义是"前面全部不成立才轮到我"。分数段模板唯一正解：阈值从大到小。写反了高档区间永远轮不到。

#### 9. 【练习】for 循环次数 [2026-09-14]

**要点**：`for (i=0; i<=5; i++)` 中 i 取 0~5 共 6 次；`<=` 比 `<` 多跑一轮。

**复习提示**：数循环先数边界——第一次和最后一次各是什么时候。循环结束后 i 停在 n（不是 n-1）。

### 位运算（1 条）

#### 10. & 与 == 的优先级坑 [2026-09-14]

**踩的坑**：`if (x & 1 == 0)` 判断偶数——编译通过但永远为假。

**错因**：`==` 优先级高于 `&`，实际算成 `x & (1==0)`。gcc 只给 warning。正确写法 `if ((x & 1) == 0)`。

**复习提示**：不止 `&`——所有比较运算符（`< > <= >= == !=`）都高于三种位运算 `& | ^`，混写必加括号。开 `-Wall` 时 gcc 会给 warning，别当耳旁风。

### 运算符（1 条）

#### 11. 逗号运算符必须加括号 [2026-09-14]

**踩的坑**：`a = (b=3, c=b+2, c*2)` 得 10；但不带括号 `x = 1, 2+3` 得 x=1。

**错因**：逗号优先级最低（比 `=` 还低），被拆成 `(x=1),(2+3)`。

**复习提示**：逗号在 C 里有两个身份——分隔符（参数表、声明列表）和运算符。看到逗号先问一句："这是哪个身份？"

### 指针（1 条）

#### 12. 【练习】*p++ 与 (*p)++ [2026-09-14 · **09-15 第 2 次做错**]

**要点**：`*p++` 是 `*(p++)`——先取 `*p` 的值，再后移指针（指针动，数据不动）；`(*p)++` 先解引用，再把数据加 1（数据动，指针不动）。

**复习提示**：后缀 `++` 优先级高，总是绑给最近的 `p`。口诀"谁动了"。`*p++` 是数组遍历的惯用法。

**09-15 二次错补充**：隔天同题再错说明"口诀会背、现场不会用"。这次的判别法换成**看值看址**——先问"表达式结束后，p 的地址变没变？"，`*p++` 变、`(*p)++` 不变；再问"数组内容变没变？"，答案正好相反。动手画一遍三个格子 + 箭头，比背口诀管用。今日自测题 Q1（`int *p = a+1; (*p)++;`）实测输出 `21 21 30`，先自己推一遍再对答案。

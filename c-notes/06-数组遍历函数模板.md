# 06 数组遍历与函数模板：统计个数 / 求和 / 最值

> 适用题型：输入 n 个数据（成绩、温度、传感器读数…），要求**用函数**统计/求和/找最值。
> 实战：统计不及格人数（2026-09-16，原题「最多 40 人，人数键盘输入」）。

## 一、结论：先背这一个骨架

这类题本质都是「**函数收数组 + 循环遍历**」，只是循环体里干的事不同。函数统一签名：

```
返回类型 函数名(数组, 元素个数)
```

记忆口诀：**函数只管「算」，main 只管「收」**——main 读数据、存数组、把「数组名 + 个数」扔给函数，函数遍历数组出结果，main 用变量接返回值。

> 数组做函数参数时退化为指针，`double s[]` 与 `double *s` 等价；函数内看不到数组长度，所以**个数 n 必须单独传**。

## 二、三个变体（全部 gcc 实测：输入 70 55 88 59 40 → `fail=3 sum=312.0 max=88.0`）

### ① 统计个数（以不及格为例，`< 60` 计数）

```c
int countFail(double s[], int n){
    int c = 0;
    for (int i = 0; i < n; i++)
        if (s[i] < 60) c++;
    return c;
}
```

### ② 求和（累加器）

```c
double sumScores(double s[], int n){
    double t = 0;
    for (int i = 0; i < n; i++)
        t += s[i];
    return t;
}
```

### ③ 找最大（擂台法）

```c
double maxScore(double s[], int n){
    double m = s[0];            /* 先拿第一个当擂主 */
    for (int i = 1; i < n; i++) /* 从第二个开始比 */
        if (s[i] > m) m = s[i];
    return m;
}
```

> ⚠️ 找最值**不能把擂主初始化成 0**：若全是负分（如 -5 -10 -3），最大值应是 -3，但 `m=0` 会错判成 0。最小值同理：初始化为 `s[0]`，循环里用 `<`。

## 三、main 怎么接（完整可跑版，即今天那题）

```c
#include <stdio.h>

int countFail(double s[], int n){
    int c = 0;
    for (int i = 0; i < n; i++)
        if (s[i] < 60) c++;
    return c;
}

int main(void){
    int n, i;
    double scores[40];                      /* 题目说最多 40 人 */

    printf("请输入人数（≤40）：\n");
    scanf("%d", &n);                        /* ← 基本类型要取地址 &n */
    if (n < 0 || n > 40){
        printf("人数非法！\n");
        return 1;                            /* 退出码 1 = 出错 */
    }

    for (i = 0; i < n; i++){
        printf("第%d个成绩：", i + 1);
        scanf("%lf", &scores[i]);           /* ← 元素也要 &scores[i] */
    }

    int fail = countFail(scores, n);        /* 传数组名（本身就是地址）+ 个数 */
    printf("不及格人数：%d\n", fail);
    return 0;
}
```

## 四、易错点（今天实战全踩过，考前专看）

| 坑 | 错的写法 | 对的写法 | 后果 |
|----|---------|---------|------|
| **scanf 读基本类型漏 `&`** | `scanf("%d", n);` | `scanf("%d", &n);` | 段错误崩溃（退出码 139） |
| **数组元素取地址** | `scanf("%lf", scores[i]);` | `scanf("%lf", &scores[i]);` | 同上崩溃 |
| **数组名多取 `&`** | `countFail(&scores, n);` | `countFail(scores, n);` | 类型不匹配警告（数组名已是地址） |
| **`%f` 读 `double`** | `scanf("%f", &a);` | `scanf("%lf", &a);` | 读取失败，值乱 |
| **`return 1` 当普通返回** | 以为"随便写" | 知道它是退出码：0=成功，非0=出错 | 不报错，但语义错 |
| **`if` 块后多余 `;`** | `} ;` | `}` | 无害空语句，卷面不整洁 |

## 五、追问预判

| 问题 | 答法 |
|------|------|
| 数组当参数为什么不用传长度？ | C 里数组传参退化成指针，函数拿不到真实长度，**约定俗成把 n 单独传**，这是 C 的惯例 |
| 找最大为什么要 `m = s[0]` 不从 0 开始？ | 若数据全为负，0 会比任何负分大，结果错；用第一个元素当初始擂主最稳 |
| 统计/求和要不要在 main 里算？ | 题目说「用函数编程」就必须在函数里算，main 只负责调；不强制时可边读边累加 |
| `double` 数组能用 `int` 函数返回吗？ | 求和/最值返回 `double`；只有「个数」返回 `int`。类型按"算出来是什么"定 |

## 六、嵌入式关联

- **「函数收缓冲 + 长度」是嵌入式标配**：传感器采样一堆数据进数组，再交给处理函数算峰值/均值/超阈值计数，和本模板一模一样。
- **数组长度单独传**对应驱动里 `write(fd, buf, len)`——内核拿到的也是 `buf` 指针 + `len`，不会替你数长度。
- **擂台法找最值**在嵌入式里常用来定量程/标定阈值，注意初始值别写成 0（尤其有符号采样）。

# 05 随机函数与流程控制

## 一、随机函数四件套

**结论**：C 的 `rand()` 是**伪随机**——确定性算法，种子相同则序列完全相同。

```c
#include <stdio.h>
#include <stdlib.h>   /* ① rand / srand / RAND_MAX */
#include <time.h>     /* ② time */

int main(void)
{
    srand((unsigned)time(NULL));   /* ③ 播种：整个程序只调一次，放 main 开头 */
    int r = rand();                /* ④ 取随机数，范围 [0, RAND_MAX] */
    printf("%d\n", r);
    return 0;
}
```

### 区间映射公式（必背）

| 需求 | 写法 |
|------|------|
| `[0, N-1]` | `rand() % N` |
| `[m, n]` | `rand() % (n - m + 1) + m` |
| `[0, 1]` 浮点 | `(double)rand() / RAND_MAX` |

掷骰子：`rand() % 6 + 1`

### 关键点

- **默认种子是 1**：不调 srand，每次运行序列都一样
- **srand 只调一次**：放循环里是经典错误
- **`(unsigned)` 强转**：`time()` 返回 `time_t`，srand 参数是 `unsigned int`，不加有 warning
- **RAND_MAX ≥ 32767**：标准只保证下限

## 二、两个实测翻车现场（教学价值最高的部分）

### 实验 1：不播种，连跑两次

```
rand: 6334 18467 41
rand: 6334 18467 41    ← 一模一样
```

原因：默认种子固定为 1。

### 实验 2：播种了，同秒内连跑两次

```
rand: 23361 12594 28678
rand: 23361 12594 28678   ← 还是一样！
```

原因：`time(NULL)` 精度是**秒**，同一秒内种子相同 → 序列相同。
**这不是 bug，恰好证明"种子决定一切"。**

### 实验 3：循环内播种

```c
for (i = 0; i < 5; i++) { srand(i); printf("%d ", rand()); }
/* 实测输出：38 41 45 48 51 */
```

输出的"随机数"全是小数字还近似等差——**随机性彻底报废**。原因：每轮重置回各自序列的开头，而不同种子的首值间隔固定（线性同余法的性质）。

### 正确做法只有一条

**srand 放循环外，整个程序调一次。**

## 三、综合例题：猜数字游戏

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int answer, guess, count = 0;

    srand((unsigned)time(NULL));          /* 播种：整个程序只一次 */
    answer = rand() % 100 + 1;            /* [1, 100] */

    printf("我想好了一个 1~100 的数，猜猜看：\n");
    while (1) {
        printf("请输入: ");
        if (scanf("%d", &guess) != 1) {
            if (feof(stdin)) {                    /* 输入流结束，体面退出 */
                printf("\n答案是 %d，下次再玩\n", answer);
                break;
            }
            printf("请输入数字！\n");
            while (getchar() != '\n');            /* 清掉字母残留 */
            continue;
        }
        count++;
        if (guess > answer)      printf("大了\n");
        else if (guess < answer) printf("小了\n");
        else { printf("猜对了！用了 %d 次\n", count); break; }
    }
    return 0;
}
```

### 开发技巧：测试时用固定种子

```bash
gcc -Wall guess.c -DFIXED -o guess.exe     # 配合 #ifdef FIXED 切换 srand(42)
```

种子固定 → 答案固定 → 才能写自动化测试。
**开发调试用固定种子，正式运行用时间种子。**

### 这道题综合了五天的知识点

| 知识点 | 位置 |
|--------|------|
| 随机函数 | `srand` + `rand() % 100 + 1` |
| 优先级 | `%` 高于 `+`，不用括号 |
| scanf 返回值 | `!= 1` 判断非法输入 |
| 缓冲区残留 | `while (getchar() != '\n')` |
| 死循环与退出 | `while(1)` + `break` + `feof` |

## 四、分支：if 家族与 switch

### if / else if / else——从上往下，命中即止

```c
int score = 85;
if (score >= 90)      printf("A\n");
else if (score >= 80) printf("B\n");   /* 命中这里，后面不再看 */
else if (score >= 60) printf("C\n");
else                  printf("不及格\n");
/* 实测输出：B */
```

**要点**：条件**从上往下**依次判断，命中一个就跳过其余全部。所以区间判断的顺序**必须从大到小**（90 → 80 → 60），写反了 85 分会掉进 `>= 60` 的 C 里。

### switch——值匹配，不是区间判断

```c
int number = 2;
switch (number) {
case 1: printf("is1 ");
case 2: printf("is2 ");      /* 匹配这里，但没有 break */
case 3: printf("is3 "); break;   /* 穿透到这，break 才停 */
default: printf("notfound "); break;
}
/* 实测输出：is2 is3 */
```

**三大要点**：

1. **没有 break 就穿透（fall-through）**：匹配 case 后一直往下执行，**不再判断**后面 case 的值，直到撞上 break 或 `}`。上面 number=2 却打印了 is3，就是穿透
2. **穿透不是 bug 是特性**：多个 case 共用一段代码时故意不写 break（`case 1: case 2: doSame(); break;`）
3. **switch 只能匹配整型/字符的常量表达式**，比不了区间和浮点

**if vs switch 选型**：区间判断用 if-else if；枚举值/菜单选项用 switch（可读性好，漏 break 编译器还会警告）。

### goto——知道有这东西就行

课堂提了 goto，用法：`goto 标签;` + `标签:`。**只在跳出多层嵌套循环时考虑**，其他场合一律用结构化写法（break/continue/函数拆分）。

## 五、for 循环：三段式

```c
for (init; condition; update) { 循环体; }
/*     ↑         ↑          ↑
     初始化   还继续吗    每轮收尾  */
```

**执行顺序**（笔试常考）：init → condition →（真则）循环体 → update → 回到 condition → …

```c
int cnt = 0;
for (int i = 0; i <= 5; i++) cnt++;
/* 实测：cnt = 6 —— i 取 0,1,2,3,4,5，共 6 次 */
```

**边界坑**：`i <= 5` 和 `i < 5` 差一次。写循环先问自己：**第一次和最后一次各是什么时候？**

**for 的三段都可空**：`for (;;)` 等价 `while (1)`，condition 为空当真处理。

**逗号表达式进场**（呼应 02 笔记）：第一段和第三段可以用逗号写多个变量——

```c
for (i = 0, j = n - 1; i < j; i++, j--) { /* 两头往中间夹，反转数组的标配 */ }
```
| 循环计数 | `count++` |

### 数学结论

100 个数二分查找最多 ⌈log₂100⌉ = **7 次必猜中**（实测 6 次猜中 76）。

## 四、追问预判

| 问题 | 答法 |
|------|------|
| 加 srand 了循环里还是一样？ | 播种写进了循环。秒级时间戳一秒内不变 |
| rand()%N 均匀吗？ | 严格说不完全均匀：`RAND_MAX+1` 不一定整除 N。作业和游戏够用；要严格均匀得用丢弃法 |
| 怎么让每次运行都不同？ | 种子每次运行不同——`time(NULL)` 最常用，但同秒内多次运行仍会撞 |

## 五、嵌入式关联

- **rand 在单片机上照样能用**（纯计算，不依赖 OS），且**可复现**——固定种子能重现随机测试路径，bug 才抓得回来
- **真正安全的随机用硬件 RNG**：STM32 的 RNG 外设靠热噪声取数，是真随机。和 rand 是两个世界

## 一、变量与数据类型

### 1. ★ 判断题 [问]
`int a;` 这行代码既定义了变量 a，也给它分配了内存。

<details><summary>答案与解析</summary>

**对。** 定义会分配内存；声明（`extern int a;`）不分配。
</details>

### 2. ★★ 改错题 [问]
```c
double d;
scanf("%f", &d);
```
找出问题。

<details><summary>答案与解析</summary>

**两处问题**：
1. `%f` 是给 float 用的，double 应该用 `%lf`
2. 严格说 scanf 里的 `%f` 会让 double 变量被按 float 解释，读到错误的值

**记忆**：`printf` 里 float/double 都用 `%f`（float 会先提升为 double），但 **scanf 里必须区分 `%f` 和 `%lf`**。
</details>

### 3. ★★ 阅读程序 [课]
```c
int a = 1;
float c = 1.25;
int d = a + c;
float e = 5 / 2;
printf("%d %.2f\n", d, e);
```
输出什么？为什么？

<details><summary>答案与解析</summary>

输出：`2 2.00`

- `d`：`a + c` 提升为 double 得 2.25，赋给 int **向零截断** → 2
- `e`：**坑在除法不在赋值**。`5 / 2` 是整数除法得 **2**（丢掉小数 .5），再转 float 还是 2.00
  （实测输出 `2 2.00`）

要得 2.50 必须写 `(float)5 / 2` 或 `5 / 2.0`。
</details>

## 二、作用域与关键字

### 4. ★★ 阅读程序 [问]
```c
int g = 1;
int main(void) {
    int a = 10;
    if (1) { int a = 20; printf("%d ", a); }
    printf("%d %d\n", a, g);
    return 0;
}
```
输出什么？现象叫什么？

<details><summary>答案与解析</summary>

输出：`20 10 1`

现象叫**遮蔽（shadowing）**：内层 `a` 是**另一个变量**，暂时盖住外层；出了 `}` 外层 a 恢复可见，仍是 10。
</details>

### 5. ★ 填空 [课]
C89 标准共有 ____ 个关键字。`sizeof` 按用途应归入 ____ 类，因为它是 ____。

<details><summary>答案与解析</summary>

**32** 个；**运算符**类；因为 sizeof 本质是**运算符**不是函数——编译期求值，`sizeof(int)` 的括号可以省略（`sizeof int` 也合法）。
</details>

### 6. ★★ 简答 [问]
`static` 修饰全局变量和修饰局部变量，分别改变什么？

<details><summary>答案与解析</summary>

- 修饰**局部**变量：改**生命周期**（出块不销毁，值保持），作用域不变
- 修饰**全局**变量/函数：改**作用域**（锁在本文件内，别的 .c 文件看不见），生命周期不变

这正是"作用域 ≠ 生命周期"的最佳例证。
</details>

### 7. ★★ 简答 [问]
为什么嵌入式代码里操作寄存器必须加 `volatile`？不加会怎样？

<details><summary>答案与解析</summary>

`volatile` 告诉编译器"这个变量随时会被程序之外的东西改掉（硬件、中断），**别优化掉对它的读写**"。

不加的后果：
```c
while (reg & 0x01);   /* 等硬件置位 */
```
编译器看到循环里没改 `reg`，会把它优化成读一次就死循环——永远等不到。
加 volatile 后每次都真去读内存/寄存器。
</details>

## 三、运算符与位运算

### 8. ★★ 阅读程序 [问]
```c
int i = 5, j;
j = i++;
printf("%d %d\n", i, j);
j = ++i;
printf("%d %d\n", i, j);
```

<details><summary>答案与解析</summary>

```
6 5      ← i++ 先用后加：j 拿旧值 5，i 变 6
8 8      ← ++i 先加后用：i 变 8，j 拿新值 8
```
</details>

### 9. ★★ 找错 [问]
```c
int x = 4;
if (x & 1 == 0) printf("偶数\n");
```
这行能编译通过吗？判断正确吗？

<details><summary>答案与解析</summary>

**能编译通过，但判断永远为假。**

`==` 优先级**高于** `&`，实际算的是 `x & (1==0)` = `x & 0` = **0**，恒假。

gcc 只给 warning（`suggest parentheses around comparison in operand of '&'`），不报错。

**正确写法**：`if ((x & 1) == 0)`

**教训**：位运算与比较混写时，括号不是可选项。
</details>

### 10. ★ 计算 [问]
```c
int a = 1, b = 2;
printf("%d %d\n", a & b, a && b);
printf("%d %d\n", ~7, 200 >> 1);
```

<details><summary>答案与解析</summary>

```
0 1            ← & 按位与得 0（1&2 = 01 & 10 = 00）；&& 逻辑与得 1（都非零）
-8 100         ← ~7 = -8（公式 ~x = -x-1）；200/2 = 100
```

**易混**：`&` 是按位、`&&` 是逻辑，长得像但完全不同。
</details>

### 11. ★★★ 简答 [问]
写出寄存器操作的四个标准写法：置 1、清 0、翻转、检测第 n 位。

<details><summary>答案与解析</summary>

```c
reg |=  (1 << n);      /* 置 1 */
reg &= ~(1 << n);      /* 清 0 */
reg ^=  (1 << n);      /* 翻转 */
if (reg & (1 << n))    /* 检测 */
```

**原理**：`1 << n` 生成"只有第 n 位是 1"的掩码；`|` 置一、`&~` 清零、`^` 翻转。
</details>

### 12. ★★★ 简答 [问]
为什么 `n % 8` 可以被优化成 `n & 7`？什么情况下不成立？

<details><summary>答案与解析</summary>

8 = 2³，`% 8` 要的就是 n 的**低 3 位**，而 7 = `00000111` 恰好只放行低 3 位。

**推广**：`n % 2^k == n & (2^k - 1)`

**反例/不成立情况**：对**有符号负整数**不成立。负数在补码下 `%` 的符号跟被除数走，而 `&` 是按位操作，结果不同。
→ **只有无符号整数才安全**，所以嵌入式里位运算变量都声明成 `unsigned`。
</details>

## 四、指针

### 13. ★★ 阅读程序 [问]
```c
int a = 5;
int *p = &a;
*p = 30;
printf("%d %d\n", a, *&a);
printf("%d\n", &*p == p);
```

<details><summary>答案与解析</summary>

```
30 30
1
```

- `*p = 30` 通过指针改 a → a 变 30
- `*&a == a`（& 和 * 互逆）
- `&*p == p` 为真（互逆）
</details>

### 14. ★★ 找错 [问]
```c
int *p;
*p = 100;
```
运行会怎样？

<details><summary>答案与解析</summary>

**未定义行为，通常 `Segmentation fault` 崩溃。**

`p` 是**野指针**——没初始化，里面是垃圾地址，往那里写数据就是踩雷。

**正确写法**：
```c
int a;  int *p = &a;  *p = 100;   /* 或者 */
int *p = NULL;  if (p != NULL) *p = 100;
```

**规则**：定义指针必须当场初始化，暂不指就 NULL。
</details>

### 15. ★★★ 简答 [问]
`*p++` 和 `(*p)++` 分别做什么？（提示：想想优先级）

<details><summary>答案与解析</summary>

- **`*p++`**：`++` 优先级高于 `*`，所以是 `*(p++)` —— 先取 `*p` 的值，再把指针 p 向后移动一位。**指针动了，数据没动**
- **`(*p)++`**：括号先解引用，再把**指向的数据**加 1。**数据动了，指针没动**

这是数组遍历里最容易写错的地方。
</details>

### 16. ★★ 简答 [问]
`*(volatile unsigned int *)0x40023830 = 0x1;` 这行代码在做什么？逐段解释。

<details><summary>答案与解析</summary>

把一个值写到**硬件寄存器**：

| 片段 | 作用 |
|------|------|
| `0x40023830` | 裸的硬件地址（数字） |
| `(volatile unsigned int *)` | 强转成"指向无符号整数的指针" |
| `*` | 解引用，访问那个地址 |
| `= 0x1` | 写入值 |
| `volatile` | 保证编译器不优化掉这次写 |

**本质和 `*p = 30` 是同一个动作**，只是目标从普通内存换成了外设寄存器。这是驱动开发最基本的写法。
</details>

## 五、输入输出与随机函数

### 17. ★★★ 找错 [问]
```c
int n; char c;
scanf("%d", &n);
scanf("%c", &c);
```
输入 `12⏎x` 后，`c` 得到什么？

<details><summary>答案与解析</summary>

**c 得到换行符（ASCII 10），不是 'x'。**

%d 吃掉 '1''2' 后停在 `\n` 前面，`%c` 不跳过空白，直接吃掉 `\n`。

**修复**：`scanf(" %c", &c);`（%c 前加空格，跳过所有空白字符）

**警告**：`fflush(stdin)` 是未定义行为，别用。
</details>

### 18. ★★ 简答 [问]
为什么 `while (scanf("%d", &n)) { ... }` 在用户输入字母时会变成死循环？

<details><summary>答案与解析</summary>

输入 `abc` 时 `%d` 读不动，返回 **0**，字母 `abc` **留在缓冲区**没人消费。
循环条件为假本应退出——但如果是 `while(scanf(...) != EOF)` 或 `while(1)` 加错误分支 `continue`，缓冲区里始终有脏数据，就会**无限循环**。

**修复两步**：
1. 检查返回值 `!= 1`
2. 清空缓冲区 `while (getchar() != '\n');`
3. 还要检查 `feof(stdin)` 处理输入流结束
</details>

### 19. ★★★ 阅读程序 [问]
```c
for (i = 0; i < 3; i++) {
    srand(i);
    printf("%d ", rand());
}
```
这样生成的"随机数"有什么问题？

<details><summary>答案与解析</summary>

**随机性报废。** 每轮 `srand(i)` 把序列重置回各自种子的**第一个值**，而不同种子的首值间隔固定（线性同余法性质），输出呈规律性的小数字。

实测（种子 0~4）：`38 41 45 48 51`

**正确做法**：`srand` 放循环外，整个程序只调一次。
</details>

### 20. ★★ 简答 [问]
为什么加了 `srand(time(NULL))`，程序在同一秒内连跑两次结果还是一样？

<details><summary>答案与解析</summary>

`time(NULL)` 精度是**秒**，同一秒内两次运行拿到的时间戳相同 → 种子相同 → 序列完全相同。

这不是 bug，恰好证明 **rand 是伪随机：种子决定一切**。

要让每次都不同，得让种子真正每次不同（如纳秒级时间、进程 ID 组合）。
</details>

## 六、综合编程题

### 21. ★★★ 编程 [问]
实现猜数字游戏：随机生成 1~100 的数，循环让用户猜，提示大/小，猜中后输出次数。要能处理用户输入字母的情况。

<details><summary>参考实现</summary>

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int answer, guess, count = 0;

    srand((unsigned)time(NULL));
    answer = rand() % 100 + 1;

    printf("我想好了一个 1~100 的数，猜猜看：\n");
    while (1) {
        printf("请输入: ");
        if (scanf("%d", &guess) != 1) {
            if (feof(stdin)) break;
            printf("请输入数字！\n");
            while (getchar() != '\n');
            continue;
        }
        count++;
        if (guess > answer)      printf("大了\n");
        else if (guess < answer) printf("小了\n");
        else { printf("猜对了！用了 %d 次\n", count); break; }
    }
    return 0;
}
```

**考察点**：随机函数播种位置、scanf 返回值校验、缓冲区清理、feof 退出、循环计数。

**数学结论**：二分法最多 7 次必猜中 100 以内的数。
</details>

### 22. ★★★ 编程 [补]
把上面游戏升级：猜对后询问"再来一局吗 (y/n)"，并统计总局数和平均猜测次数。

<details><summary>思路提示</summary>

- 局数循环用 `do...while` 或 `while(1)` + 判断
- **关键坑**：读 `y/n` 时用 `scanf(" %c", &ans)`，**前面必须加空格**——否则会吃到上一次输入留下的换行符
- 平均次数 = `(double)总次数 / 总局数`，注意用浮点除法
</details>

### 23. ★★★ 编程 [问]
输入某班学生某门课的成绩（最多不超过 40 人），当输入为负值时表示输入结束。用函数编程统计成绩高于平均分的学生人数。

<details><summary>参考实现</summary>

```c
#include <stdio.h>

/*
 * 统计成绩高于平均分的学生人数，同时通过指针带出平均分
 * score: 成绩数组
 * n:     实际输入的学生人数
 * pAvg:  用于输出平均分的指针
 * 返回:  高于平均分的人数
 */
int countAboveAverage(double score[], int n, double *pAvg)
{
    int i;
    int cnt = 0;
    double sum = 0.0;

    if (n <= 0) {
        if (pAvg) *pAvg = 0.0;
        return 0;
    }

    for (i = 0; i < n; i++) {
        sum += score[i];
    }

    *pAvg = sum / n;

    for (i = 0; i < n; i++) {
        if (score[i] > *pAvg) {
            cnt++;
        }
    }

    return cnt;
}

int main(void)
{
    int i;
    int n = 0;
    double scores[40];
    double x;
    double avg;

    printf("Enter scores (negative number to end, up to 40 students):\n");

    for (i = 0; i < 40; i++) {
        printf("Student %d: ", i + 1);
        if (scanf("%lf", &x) != 1) {
            printf("Invalid input. Stop.\n");
            break;
        }

        if (x < 0) {
            break;
        }

        scores[n] = x;
        n++;
    }

    if (n == 0) {
        printf("No scores entered.\n");
        return 0;
    }

    int above = countAboveAverage(scores, n, &avg);

    printf("\nTotal students: %d\n", n);
    printf("Average score: %.2f\n", avg);
    printf("Students above average: %d\n", above);

    return 0;
}
```

**运行示例**：
```
Enter scores (negative number to end, up to 40 students):
Student 1: Student 2: Student 3: Student 4: Student 5:
Total students: 4
Average score: 75.00
Students above average: 2
```

**考察点**：数组作函数参数、函数返回值、通过指针返回多个结果、`scanf` 格式符 `%lf`、负数结束输入的处理、实际人数 `n` 与数组容量 40 的区分。

</details>

## 七、新讲实测：补码 · 浮点 · 分支循环 [2026-09-14 课堂]

> 本组题目全部经本机 gcc（MinGW 6.3.0）实测验证。

### 23. ★★ 选择 [课]
```c
int c1 = -5;
printf("%d\n", ~c1 + 1);
```
输出什么？

A. -5    B. 5    C. 4    D. 6

<details><summary>答案与解析</summary>

**B（5）。** 负数按补码存：绝对值取反加一。对 -5 做 `~ + 1` 等于把这套操作再走一遍，得到相反数 5。
同族结论：`~5 + 1 = -5`（正变负）、`~(-x) + 1 = x`（负变正）。
</details>

### 24. ★★★ 选择 [课]
```c
char c = 127;
c = c + 1;
printf("%d\n", c);
```
输出什么？

A. 128    B. -128    C. 0    D. 未定义输出

<details><summary>答案与解析</summary>

**B（-128）。** signed char 最大值 127，加 1 后**回绕**到最小值 -128（补码系统的必然结果：最高位进位成了符号位）。
有符号溢出严格说是未定义行为，但补码机器上实际表现就是回绕——考试按 -128 答。
</details>

### 25. ★★ 选择 [课]
```c
unsigned int ui = 0;
ui = ui - 1;
printf("%u\n", ui);
```
输出什么？

A. -1    B. 0    C. 4294967295    D. 1

<details><summary>答案与解析</summary>

**C（4294967295）。** 无符号数没有负数，0 再减就**绕回最大值**（42 亿 - 1）。
这就是 `for (unsigned i = n-1; i >= 0; i--)` 永远退不出去的原因——`i >= 0` 对无符号恒成立。
</details>

### 26. ★★★ 选择 [课]
```c
int a = -1;
unsigned int b = 1;
printf("%d\n", a < b);
```
输出什么？

A. 1（-1 确实小于 1）    B. 0    C. 编译报错    D. 不确定

<details><summary>答案与解析</summary>

**B（0）。** 有符号和无符号比较时，**有符号先转无符号**：-1 变成 4294967295，再和 1 比 → 假，输出 0。
嵌入式面试经典：编译器加 `-Wsign-compare` 能抓到这类比较。
</details>

### 27. ★ 选择 [课]
float 和 double 的内部结构分别是（符号位+指数位+尾数位）？

A. float: 1+8+23（4字节），double: 1+11+52（8字节）
B. float: 1+11+52，double: 1+8+23
C. float: 1+8+23，double: 1+8+55
D. 两者结构相同，只是总位数不同

<details><summary>答案与解析</summary>

**A。** float：1 符号 + 8 指数 + 23 尾数 = 32 位，有效精度 6~7 位十进制；
double：1 符号 + 11 指数 + 52 尾数 = 64 位，有效精度 15~16 位。
（float.h 的 `FLT_DIG=6`、`DBL_DIG=15`，实测一致）
</details>

### 28. ★★★ 选择 [课]
```c
printf("%d\n", 0.1 + 0.2 == 0.3);
```
输出什么？为什么？

A. 1，数学上相等
B. 0，0.1 和 0.2 在二进制里是无限循环小数，存储时被截断
C. 1，编译器会自动修正
D. 0，因为 == 只能比较整数

<details><summary>答案与解析</summary>

**B。** 实测：`0.1 + 0.2 - 0.3 = 5.55e-17`，不是 0。
二进制没法精确表示 0.1（就像十进制没法精确表示 1/3），存进有限的尾数位只能截断。
**正确比较**：`fabs(a - b) <= 容差`（如 1e-9）。浮点数永远不要用 == 直接比。
</details>

### 29. ★★ 选择 [课]
C 语言里 `sizeof('a')` 的值是？

A. 1，因为 'a' 是字符    B. 4，因为字符字面量的类型是 int    C. 不确定    D. 编译报错

<details><summary>答案与解析</summary>

**B（4）。** C 标准：字符字面量 `'a'` 的类型是 **int**（实测 sizeof('a')=4）。
C++ 里才是 char（=1）——C/C++ 面试对比经典题。
</details>

`sizeof(int)` 的返回值类型和对应 printf 格式符是？

</details>

### 31. ★★ 自测 [课]
```c
float f = 0.1f;
printf("%.17f\n", (double)f);
```
实测输出 `0.10000000149011612`，不是 0.10000000000000000。为什么？

<details><summary>答案与解析</summary>

float 只有 23 位尾数（约 7 位十进制有效数字），**装不下 0.1 的二进制精确表示**，存进去的是"最接近 0.1 的那个 float"。
提升成 double 打印时，这个近似值暴露无遗。
一句话：**精度在存进去的那一刻就已经丢了，打印只是如实招来**。
</details>

### 32. ★★ 选择 [课·老师课堂原题]
```c
int number = 2;
switch (number) {
case 1: printf("is1 ");
case 2: printf("is2 ");
case 3: printf("is3 "); break;
default: printf("notfound "); break;
}
```
输出什么？

A. is2    B. is2 is3    C. is2 is3 notfound    D. is1 is2 is3

<details><summary>答案与解析</summary>

**B（is2 is3）。** 匹配 case 2 后**没有 break，发生穿透（fall-through）**：继续执行 case 3 的代码，**不再判断** case 3 是否匹配，直到撞上 break 才停。
穿透是特性不是 bug：`case 1: case 2: 共用代码; break;` 就是故意穿透。
</details>

### 33. ★★ 选择 [课]
```c
int score = 85;
if (score >= 60)      printf("C\n");
else if (score >= 80) printf("B\n");
else if (score >= 90) printf("A\n");
else                  printf("不及格\n");
```
输出什么？暴露了什么问题？

A. B，区间判断正确    B. C，区间顺序写反了    C. A    D. 编译报错

<details><summary>答案与解析</summary>

**B（C）。** if-else if 从上往下**命中即止**：85 先撞上 `>= 60` 为真，输出 C，后面不再看。
**区间判断必须从大到小写**（90 → 80 → 60），顺序反了高档区间永远轮不到。
</details>

### 34. ★★ 选择 [课]
```c
int cnt = 0;
for (int i = 0; i <= 5; i++) cnt++;
printf("%d\n", cnt);
```
输出什么？

A. 5    B. 6    C. 7    D. 4

<details><summary>答案与解析</summary>

**B（6）。** i 取 0,1,2,3,4,5 共 6 次；`<=` 比 `<` 多跑一轮。
写循环先问自己：**第一次和最后一次各是什么时候？**边界差一是 off-by-one 的头号来源。
</details>

### 35. ★★ 选择 [课]
`for (init; condition; update)` 的执行顺序是？

A. init → condition → 循环体 → update → 回到 condition
B. init → 循环体 → update → condition
C. init → update → condition → 循环体
D. 每轮都执行一遍 init

<details><summary>答案与解析</summary>

**A。** init **只执行一次**；之后是"查 condition → 跑循环体 → 跑 update → 再查 condition"的循环。
condition 为空时**当真处理**（`for(;;)` 等价 `while(1)`）。
</details>

### 36. ★★ 自测 [课]
`for (;;)` 和 `while (1)` 等价吗？分别在什么场合用？

<details><summary>答案与解析</summary>

**语义等价**：condition 为空按"真"处理，都是无限循环，退出靠 break/return/goto。

- `while (1)`：可读性好，条件明确写出来，初学推荐
- `for (;;)`：老牌 C 程序员风格，某些编译器对 `while(1)` 报"常量条件"警告时用它躲开
- 嵌入式 main 里的主循环两种都常见：`for(;;) { 处理事件; 喂狗; }`
</details>

### 37. ★★★ 选择 [课]
```c
printf("%d\n", ~4);
```
输出什么？

A. 4    B. -4    C. -5    D. 5

<details><summary>答案与解析</summary>

**C（-5）。** 公式：**`~x = -(x+1)`**（实测 ~4=-5、~7=-8）。
比"取反加一"少一步：`~x + 1 = -x` 是求相反数，`~x` 本身直接跳到 -(x+1)。
推导：x + ~x = 全 1 = -1 → ~x = -1 - x。
</details>

### 38. ★★ 选择 [问]
```c
int arr[] = {1, 2, 3};
int *p = arr;
int a = *p++;
(*p)++;
```
执行后 `a`、`arr[0]`、`arr[1]` 的值分别是？

A. a=1, arr[0]=2, arr[1]=3  
B. a=1, arr[0]=1, arr[1]=3  
C. a=2, arr[0]=1, arr[1]=3  
D. a=1, arr[0]=1, arr[1]=4

<details><summary>答案与解析</summary>

**B。**
- `*p++` 等价于 `*(p++)`：先取 `*p`（arr[0]=1）赋给 a，然后 p 指向 arr[1]。
- `(*p)++` 先解引用得到 arr[1]=2，再把它加 1，arr[1] 变成 3；p 仍然指向 arr[1]。
- arr[0] 从头到尾没被碰过，保持 1。
</details>

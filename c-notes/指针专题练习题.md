### 39. ★★ 阅读程序 [补]
```c
int a[3] = {10, 20, 30};
int *p = a;
printf("%d %d\n", *(p + 1), *(p + 2));
```
输出什么？

<details><summary>答案与解析</summary>

输出：`20 30`

`p` 指向 `a[0]`；`p + 1` 按 `sizeof(int)`（4 字节）走一步到 `a[1]`，`*(p+1)` = 20；`*(p+2)` = 30。本质和 `a[1]`、`a[2]` 完全等价。
</details>

### 40. ★★★ 选择 [补]
```c
void f(int x[]) { printf("%zu\n", sizeof(x)); }
int main(void) { int a[5]; printf("%zu\n", sizeof(a)); f(a); }
```
在 64 位环境，两行分别输出？

A. 20 20　　B. 20 8　　C. 5 1　　D. 20 4

<details><summary>答案与解析</summary>

**B（20 8）。** `sizeof(a)` 是数组原貌 `5*4 = 20`；数组传参退化成 `int*`，64 位下指针占 **8** 字节，所以 `sizeof(x) = 8`。
本机 32 位是 4（笔记已注明）——规则一样，只是指针大小翻倍。
**教训**：数组长度必须单独作为参数传，不能靠函数内 `sizeof` 算。
</details>

### 41. ★★★ 找错 [补]
```c
char *s = "hello";
s[0] = 'H';
printf("%s\n", s);
```
这代码运行会怎样？

<details><summary>答案与解析</summary>

**`Segmentation fault`（段错误，实测 exit 139）。**

`s` 指向的是**字符串字面量**，存在只读数据段；强行写 `s[0]='H'` 触发内存保护。
**正确**：需要修改就用数组 `char s[] = "hello";`（内容在栈上，可改）。
</details>

### 42. ★★ 简答 [补]
`const int *p` 和 `int * const p` 有什么区别？

<details><summary>答案与解析</summary>

看 `const` 在 `*` 的哪边：
- `const int *p`（或 `int const *p`）：`const` 在 `*` **左边** → 锁**数据**，`*p` 不可改，但 `p` 可以指向别处
- `int * const p`：`const` 在 `*` **右边** → 锁**指针**，`p` 不可改（不能 `p++`），但 `*p` 可改

口诀：**const 贴左锁数据，贴右锁指针。**
</details>

### 43. ★★★ 选择 [补]
```c
int *p[3];
int (*q)[3];
printf("%zu %zu\n", sizeof(p), sizeof(q));
```
64 位环境输出？

A. 3 3　　B. 24 8　　C. 12 4　　D. 8 8

<details><summary>答案与解析</summary>

**B（24 8）。**
- `int *p[3]`：是**指针数组**——3 个 `int*` 元素的数组，`3 * 8 = 24`
- `int (*q)[3]`：是**数组指针**——指向"含 3 个 int 的数组"的指针，`1 * 8 = 8`

记忆：`[]` 优先级高于 `*`，`*` 先贴变量名就是指针。`p` 是数组（装指针），`q` 是指针（指整个数组）。
</details>

### 44. ★★ 简答 [补]
函数名是什么？函数指针有什么用？

<details><summary>答案与解析</summary>

- 函数名**本身就是函数指针**（函数的入口地址），所以 `f` 和 `&f` 都能赋给函数指针变量。
- 函数指针的经典用途是**回调**：把函数当参数传给另一个函数。例如标准库 `qsort` 的比较函数 `int (*cmp)(const void*, const void*)`，由调用者提供比较规则。
</details>

### 45. ★★★ 找错 [补]
```c
int* f(void) { int t = 10; return &t; }
int main(void) { int *p = f(); printf("%d\n", *p); }
```
有什么问题？

<details><summary>答案与解析</summary>

**返回了局部变量的地址。** 编译即警告 `function returns address of local variable`，运行时是**未定义行为**——`t` 的栈帧在 `f` 返回后已销毁，`*p` 读到的是垃圾值，甚至可能崩溃。

**正确做法**：让调用者提供空间（传指针）、用 `static` 延长生命周期，或 `malloc`（记得 free）。
</details>

### 46. ★★★ 找错 [补]
```c
int *p = malloc(5 * sizeof(int));
p[0] = 1;
free(p);
p[0] = 2;
```
指出所有问题。

<details><summary>答案与解析</summary>

两处问题：
1. **`malloc` 没判 `NULL`**：申请失败返回 `NULL`，后面 `p[0]=1` 直接崩。
2. **`free` 后还用 `p`**：内存已归还系统，`p` 变成**悬空指针**，再写 `p[0]` 是未定义行为。

**正确写法**：
```c
int *p = malloc(5 * sizeof(int));
if (p == NULL) { /* 处理失败 */ return; }
p[0] = 1;
free(p);
p = NULL;        /* free 后立刻置 NULL，后续用前判空 */
```
</details>

### 47. ★★ 简答 [补]
二级指针 `int **pp` 有什么用？

<details><summary>答案与解析</summary>

两个主要用途：
1. **在函数里改一个一级指针本身**：比如让函数内部 `malloc` 出内存并让外面的指针指向它，必须传 `int**`（传 `int*` 只能改它指向的数据，改不了指针变量本身）。
2. **指向字符串数组**：`char *argv[]`（main 的参数）传给函数时退化成 `char **argv`。
</details>

### 48. ★★★ 找错 [补]
```c
int x = 5;
void *vp = &x;
printf("%d\n", *vp);
```
能编译通过吗？

<details><summary>答案与解析</summary>

**不能。** 编译报错 `invalid use of void expression`。
`void*` 是"通用指针"，但**不知道指向什么类型**——没有大小信息，所以不能解引用、也不能做指针算术（`vp+1` 也不行）。

**正确**：先强转回具体类型：`printf("%d\n", *(int*)vp);`
（`malloc` 返回 `void*`，在 C 里可隐式转成任意指针，所以平时 `int *p = malloc(...)` 不用手写强转；但解引用前它已是你指定的类型了。）
</details>

### 49. ★★★ 找错 [补]
```c
int a[5];
a++;
```
能编译通过吗？

<details><summary>答案与解析</summary>

**不能。** 编译报错 `lvalue required as increment operand`（需要可修改的左值）。
数组名 `a` 的值虽是首地址，但它是**常量**，没有自己的存储位置，不能被赋值或 `++`。

**正确**：想移动就用另一个指针 `int *p = a; p++;`。
</details>

### 50. ★★ 阅读程序 [补]
```c
char s[] = "abc";
char *p = s;
while (*p) { putchar(*p); p++; }
```
输出什么？

<details><summary>答案与解析</summary>

输出：`abc`

`p` 从首字符开始；`*p` 非 `'\0'` 就打印当前字符并后移一步；遇到字符串结尾的 `'\0'`（`*p` 为假）停止。这是指针遍历字符串最标准的写法。
</details>

### 51. ★★ 找错 [补]
```c
int a;
scanf("%d", a);
```
错在哪？

<details><summary>答案与解析</summary>

**漏写 `&`。** `scanf` 的 `%d` 需要**地址**才能把读到的数写进 `a`；写成 `a` 是把 `a` 当时的值当地址往里写，直接崩溃。

**正确**：`scanf("%d", &a);`
（例外：数组名 `scanf("%s", str)`、字符串指针本身已经是地址，不用加 `&`。）
</details>

# 02 基础语法：变量、作用域、关键字、运算符、隐式转换

## 一、变量是什么

**结论**：变量是内存中一块**有名字的存储空间**，程序通过名字读写它。

```
int a = 25;
     │
     ├── 名字 a     → 编译后变成地址，CPU 只认地址
     ├── 类型 int   → 决定占 4 字节、按什么格式解释
     └── 值 25      → 内存里实际的二进制内容
```

"变"的含义：值在程序运行期间可以改（`a = 30;`），名字和类型不变。

### 关键点

- **定义 vs 声明**：定义分配内存（`int a;`），声明只告知编译器（`extern int a;`），不分配
- **必须先定义后使用**
- **命名规则**：字母/数字/下划线，不能数字开头，不能用关键字，区分大小写
- **未初始化的局部变量是垃圾值**（最常见坑）

### 追问预判

| 问题 | 答法 |
|------|------|
| 变量与常量的区别？ | 变量运行时可改；常量（`const int x = 5;` 或字面量）不可改。`const` 变量本质仍是内存，只是编译器禁止写 |
| int 占多少内存？ | 通常 4 字节，但标准只规定 `short ≤ int ≤ long`，具体看平台。嵌入式上 int 可能是 16 位，所以用 `stdint.h` 的 `uint32_t` 等定宽类型 |
| 为什么要有类型？ | 内存里只有 0/1，类型告诉 CPU 这串二进制怎么解释、按几字节读写。同样 4 字节，当 int 看是 25，当 float 看完全是另一个数 |

## 二、作用域

**结论**：作用域是变量有效的范围，出了范围名字就不可见。

### 四种作用域

| 作用域 | 出现位置 | 有效范围 | 例子 |
|--------|---------|---------|------|
| **块作用域** | 函数体、if/for 的 `{}` 内 | 定义处 → `}` | 局部变量 |
| **文件作用域** | 所有函数外面 | 定义处 → 文件末尾 | 全局变量 |
| **函数原型作用域** | 函数声明的参数 | 只在那一行 | `int add(int x, int y);` |
| **函数作用域** | 只针对标签（goto 用） | 整个函数 | `label:` |

### 遮蔽（shadowing）

```c
int a = 10;
if (1) {
    int a = 20;   /* 新的变量，遮住外面那个 */
}
/* 出了 if，外面 a 还是 10 */
```

内层和外层是**两个不同的变量**，内层暂时盖住外层的名字。

### 作用域 ≠ 生命周期

- **作用域**：空间上哪里可见（编译期概念）
- **生命周期**：时间上内存何时存在（运行期概念）
- **反例**：`static` 局部变量——作用域仍限块内，但生命周期贯穿整个程序

### 追问预判

| 问题 | 答法 |
|------|------|
| 局部 vs 全局？ | 两维度：作用域（块内 vs 全文件）+ 生命周期（出块销毁 vs 程序全程）。全局变量不初始化自动为 0，局部是垃圾值 |
| 全局变量能跨 .c 文件用吗？ | 能，但要 `extern int g;` 声明——引出**链接属性**：`extern` 去别处找定义，`static` 把作用域锁在本文件内 |

## 三、关键字

**结论**：关键字是 C 语言预定义的保留字（C89 共 **32 个**），不能用作变量名/函数名。

### 按用途分四组

| 分组 | 关键字 | 数量 |
|------|--------|------|
| **数据类型** | int, char, float, double, short, long, signed, unsigned, void, struct, union, enum | 12 |
| **存储类别** | auto, static, extern, register, typedef, const, volatile | 7 |
| **流程控制** | if, else, switch, case, default, for, while, do, break, continue, goto, return | 12 |
| **运算符级** | sizeof | 1 |

### 易混点

- **`sizeof` 是运算符**不是函数——编译期求值，`sizeof(int)` 括号可省
- **`const` 不是"常量"是"只读变量"**——内存还在，只是不许写
- **`auto` 两副面孔**：C89 里是"普通局部变量"（写了等于没写）；C11 起变成类型自动推导
- **关键字全小写**：`Int`、`INT` 不是关键字，是合法标识符
- **C89 是 32 个**，C99 新增 5 个（inline, restrict, _Bool, _Complex, _Imaginary）

### 追问预判

| 问题 | 答法 |
|------|------|
| static 和 extern？ | `static` 私有化：修饰局部变量改生命周期，修饰全局变量/函数改作用域（锁本文件）；`extern` 引用外部，自己不分配内存 |
| register 干嘛的？ | 建议编译器放 CPU 寄存器加快访问，只是建议；对 register 变量**不能取地址**。现代编译器自己优化，基本不用了 |
| volatile 何时用？ | 告诉编译器"这变量随时被程序外的东西改掉（硬件寄存器、中断），别优化掉对它的读写"。嵌入式**面试必考** |

## 四、运算符

**结论**：运算符是表示数据运算的符号，配合操作数构成表达式，**每个表达式都有值和类型**。

### 六大类

| 类别 | 运算符 | 备注 |
|------|--------|------|
| 算术 | `+ - * / %` `++ --` | 注意 / 和 % 的坑 |
| 关系 | `> < >= <= == !=` | 结果只有 1 或 0 |
| 逻辑 | `&& \|\| !` | 有短路特性 |
| 位运算 | `& \| ^ ~ << >>` | 嵌入式的看家本领 |
| 赋值 | `= += -= *= /= %=` | 别和 == 搞混 |
| 其他 | `?:` `sizeof` `,` `&` `*` | 条件、字节、取地址 |

### 五大必考坑

**① 整数除法丢小数**
```c
int a = 7 / 2;        /* = 3，不是四舍五入，直接丢 */
double b = 7.0 / 2;   /* = 3.5，有一个是浮点就按浮点除 */
int c = -7 % 2;       /* = -1，% 结果符号跟被除数走 */
```

**② ++ 前置 vs 后置**
```c
int i = 5, j;
j = i++;   /* 先用后加：j=5, i=6 */
j = ++i;   /* 先加后用：j=7, i=7 */
```

**③ = 与 ==**
`if (x = 0)` 是赋值，值恒为 0，**永远为假**且不报错。
防御写法：常量放左边 `if (0 == x)`。

**④ 短路求值**
```c
(a && b)   /* a 为假 → b 不算 */
(a || b)   /* a 为真 → b 不算 */
```
经典题：`if (i != 0 && 1/i > 0)` —— 短路救你一命。

**⑤ 位运算 vs 逻辑运算**
`1 & 2 = 0`，但 `1 && 2 = 1`。

### 优先级（背梯度不背全表）

```
! ~ ++ --  >  * / %  >  + -  >  << >>  >  关系  >  == !=  >  &  >  ^  >  &&  >  ||  >  赋值 =
```
自测：`x = 3 > 2 + 1;` → 先 `2+1=3`，再 `3>3` 得 0，最后赋值 → **x = 0**。

### 完整 12 级速查表（课堂版，查表用不用背）

| 级 | 运算符 | 说明 |
|---|--------|------|
| 1 | `()` `[]` `.` `->` | 括号/下标/成员访问，永远最高 |
| 2 | `++` `--` `+` `-` `!` `~` `&` `*` | 单目运算（含取地址、解引用） |
| 3 | `*` `/` `%` | 算术 |
| 4 | `+` `-` | 算术 |
| 5 | `<<` `>>` | 移位 |
| 6 | `<` `>` `<=` `>=` | 大小比较 |
| 7 | `==` `!=` | 相等比较（**比大小还低一级**） |
| 8 | `&` `^` `\|` | 按位与/异或/或 |
| 9 | `&&` | 逻辑与 |
| 10 | `\|\|` | 逻辑或 |
| 11 | `?:` | 三元条件 |
| 12 | `=` `+=` 等 | 赋值，**最低级之一**（逗号更低） |

**老师口诀：就近原则**——优先级决定谁先跟操作数"结合"。
对照错题本：`x & 1 == 0` 错在 7 级的 `==` 先于 8 级的 `&` 结合，实际是 `x & (1==0)`。

### 结合性

- **从右到左**：单目运算、赋值、条件 `?:`
- **从左到右**：其余双目运算符
- 逗号 `,` 优先级比赋值还低——所以 `x = 1, 2+3` 是 `(x=1), (2+3)`

## 五、隐式转换

**结论**：**运算时"就高不就低"（类型提升），赋值时"向零截断"**。

```c
int a = 1;
float c = 1.25;
int d = a + c;

/* 第一步：a 提升为 double，a+c = 2.250000 */
/* 第二步：赋给 int，小数丢弃 → d = 2 */
```

### 截断不是四舍五入

| 右边值 | 赋给 int |
|--------|---------|
| 2.25 | 2 |
| 2.75 | **2** |
| 2.999 | **2** |
| -2.25 | **-2**（向零取整） |

### 相关坑

- **想四舍五入**：`d = (int)(x + 0.5);` 或用 `round()`（要 `-lm`）
- **`float d = a / b` 的坑在除法**：`5/3` 先得整数 1，再转 float 还是 1.0。要写 `(float)a / b`
- **默认不警告**：精度丢失是 bug 重灾区，嵌入式里 float 算的电流值塞进 int 寄存器，小数就这么丢了

## 六、嵌入式关联

- **存储类别那一组**是嵌入式高频：`static` 做模块化、`const` 把查找表放 Flash、`volatile` 防寄存器读写被优化
- **数据类型配 `stdint.h`**：`uint8_t`/`uint32_t` 保证跨平台宽度一致
- **作用域决定变量位置**：栈 / data 段 / bss 段，这是看启动文件（startup）的必备知识

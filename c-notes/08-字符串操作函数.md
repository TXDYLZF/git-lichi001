## 0. 先搞懂：C 里的"字符串"到底是什么

这是**所有字符串函数的前提**，没懂这个后面全会懵。

C 语言**没有字符串类型**。所谓"字符串"，就是一串 `char`，并且**以 `'\0'` 结尾的那一格才算收尾标志**。

```
"hi" 在内存里其实是 3 个字节：

  下标:  0    1    2
        ┌────┬────┬────┐
        │ 'h'│ 'i'│'\0'│   ← 结尾这个 '\0'（ASCII 0）是"结束标记"
        └────┴────┴────┘
                ↑ 字符串长度算 2，但占 3 个字节
```

⚠️ **铁律**：字符串函数（strlen/strcpy/strcmp…）全都靠找 `'\0'` 来判断"到哪结束"。**没有 `'\0'` 的字符数组不是合法的字符串**，这些函数会一直往后读，读到内存乱码甚至崩溃。

两种产生字符串的方式：
```c
char a[] = "hi";        // ✅ 编译器自动补 '\0'，a 有 3 字节
char b[2] = {'h','i'};  // ❌ 没有 '\0'，不是字符串！strlen(b) 会越界乱读
char c[10] = "hi";      // ✅ 只初始化前 3 字节，剩下 7 字节全是 '\0'
```

**长度 vs 占用（最容易混）：**
| | 含义 | 例 "hi" |
|---|---|---|
| `strlen(s)` | 运行时**数到 `'\0'` 为止的字符数** | 2 |
| `sizeof(s)` | 编译期算**整个数组占多少字节** | 3（数组 [3]） |

## 1. strlen：数一数有多长

**人话**：从开头一直往后数，数到 `'\0'` 停下，返回数了多少个。

```c
#include <string.h>
size_t strlen(const char *s);
```

**内存图**：`char s[] = "hello";`
```
  h  e  l  l  o  \0
  └──── 数 5 个 ───┘↑ 在 \0 前停下
  返回 5
```

```c
char s[] = "hello";
printf("%d\n", (int)strlen(s));   // 5
printf("%d\n", (int)sizeof(s));   // 6（数组 [6]，含 '\0'）
```

**两个大坑（实测）：**
1. `strlen` ≠ `sizeof`，见上。
2. 返回值是 `size_t`（无符号整数）。下面这行**永远为假**，因为无符号数做减法不会变负：
   ```c
   if (strlen(a) - strlen(b) < 0)   // ❌ 永远不进，小减大会回绕成天文数字
   if (strlen(a) < strlen(b))       // ✅ 正确写法
   ```

**口诀**：strlen 数字符不算 `'\0'`，返回无符号别瞎减。

> **嵌入式关联**：strlen 是 O(n)（一个一个扫到结尾）。协议帧里**绝不要靠 strlen 找长度**——截断的帧没有 `'\0'`，strlen 会一路读到越界。协议要自己带"长度字段"。

## 2. strcpy：整串拷贝

**人话**：把 src 那一串（连结尾的 `'\0'`）原样抄到 dst，从 dst 开头开始写。

```c
char *strcpy(char *dst, const char *src);
```

**内存图**：`char dst[6]; strcpy(dst, "hi");`
```
  执行前  dst[6] 全是 ? ?? ?? ?? ?? ??
  执行后  ┌────┬────┬────┬────┬────┬────┐
          │ 'h'│ 'i'│'\0'│ ?? │ ?? │ ?? │  ← 只写前 3 字节，后面不动
          └────┴────┴────┴────┴────┴────┘
```

```c
char dst[20];
strcpy(dst, "hello");          // dst 现在是 "hello"
```

**最大的坑**：dst 必须**足够大**装得下 src 整个串（含 `'\0'`）。装不下 = 缓冲区溢出 = 栈被踩坏 = 程序崩溃或被攻击。这也是为什么工程里基本不用裸 strcpy。

**口诀**：strcpy 不数大小，dst 不够就炸。

---

## 3. strncpy：最多拷 n 个（但有个反直觉的坑）

**人话**：和 strcpy 一样，但**最多只拷贝 n 个字节**，防止溢出。

```c
char *strncpy(char *dst, const char *src, size_t n);
```

**内存图（① src 比 n 长，危险！）**：`char buf[6]; strncpy(buf, "hello world", 5);`
```
  要拷 5 字节 "hello"，刚好填满 buf[0..4]，但 'h' 'e' 'l' 'l' 'o' 之后没有 '\0'！
  ┌────┬────┬────┬────┬────┐
  │ h  │ e  │ l  │ l  │ o  │   ← 没有结束符！buf 不是合法字符串
  └────┴────┴────┴────┴────┘
  printf("%s", buf);  // ❌ 未定义行为：printf 继续往后读垃圾
```

**内存图（② src 比 n 短，安全）**：`strncpy(buf, "hi", 5);`（buf 有 8 字节）
```
  ┌────┬────┬────┬────┬────┬────┬────┬────┐
  │ h  │ i  │ \0 │ \0 │ \0 │ ?? │ ?? │ ?? │  ← 不够的位全部补 '\0'
  └────┴────┴────┴────┴────┴────┴────┴────┘
```

**结论（实测确认）：**
- src 长度 **≥ n**：只拷 n 字节，**不写 `'\0'`** → 必须手动补。
- src 长度 **< n**：剩余位**补 `'\0'`** → 自动合法。

**安全写法**：
```c
char buf[6];
strncpy(buf, "hello world", sizeof buf - 1);
buf[sizeof buf - 1] = '\0';           // 手动补，绝对保险
// 或者更省心：直接用下面的 snprintf
```

**口诀**：strncpy 拷贝 n 个就停，src 长不补零——拷完自己补。

## 4. strcat / strncat：拼在尾巴上

**人话**：strcpy 是"覆盖 dst 开头"，strcat 是"找到 dst 的 `'\0'`，从那里开始把 src 接上去"。

```c
char *strcat(char *dst, const char *src);
char *strncat(char *dst, const char *src, size_t n);
```

**内存图**：`char url[32] = "http://"; strcat(url, "x.com");`
```
  执行前  "http://\0..............."
  找到 \0    ↓ 从这里接
  执行后  "http://x.com\0.........."
```

**strncat 的惊喜（和 strncpy 反着来，必考）**：
- `strncpy`：src≥n 时**不补** `'\0'`。
- `strncat`：**追加 n 个字符后，总会再补一个 `'\0'`**。所以它比 strncpy 安全。

```c
char url[32] = "http://";
strncat(url, "x.com", 3);            // 只接 "x.c"，然后自动补 '\0'
```

**坑**：dst 必须是**够大的可写数组**。`char *p = "abc"; strcat(p, "d");` 段错误——字符串字面量在只读内存区，不能写。

**口诀**：strcat 接在 `\0` 后；strncat 接完必补零（和 strncpy 相反）。

## 5. strcmp / strncmp：比大小，不是比长度！

**人话**：`==` 比较的是地址；`strcmp` 才比较**内容**。它从第一个字符开始逐个比 ASCII 码，谁先更小就返回负，相等继续，一直到某边先到 `'\0'`。

```c
int strcmp(const char *s1, const char *s2);     // 返回 <0 / 0 / >0
int strncmp(const char *s1, const char *s2, size_t n);  // 只比前 n 个
```

**推演示例**：`strcmp("abc", "abd")`
```
  第1位 'a' vs 'a' → 相等，继续
  第2位 'b' vs 'b' → 相等，继续
  第3位 'c'(99) vs 'd'(100) → c<d → 返回负数（约 -1）
```

**字典序直觉**：比的是"谁在字典里排前面"，和长度无关。
```
  "abc"  < "abcd"      // 前3位一样，短的先结束 = 小
  "abc"  < "abd"
  "Apple" < "apple"    // 大写 A(65) < 小写 a(97)
```

**最大坑（考过 N 次）**：
```c
char a[] = "hi", b[] = "hi";
if (a == b)            // ❌ 比的是两个数组的地址，永远不相等
if (strcmp(a, b) == 0) // ✅ 内容相等才进
```

用法：
```c
if (strcmp(s, "exit") == 0) break;     // 相等
if (strncmp(s, "GET ", 4) == 0) ...;   // 只比前缀
```

**口诀**：比内容用 strcmp，== 比的是地址；返回三态别当布尔。

## 6. strchr / strrchr / strstr：去里面找东西

**人话**：在一串里找"某个字符第一次出现/最后一次出现/某个子串"，找到就**返回指向那个位置的指针**，找不到返回 `NULL`。

```c
char *strchr (const char *s, int c);    // 第一次
char *strrchr(const char *s, int c);    // 最后一次（r = reverse 反向）
char *strstr (const char *hay, const char *needle); // 找子串
```

**内存图**：`strchr("hello world", 'o')` 返回指向第一次出现的 'o' 的指针
```
  h e l l o   w o r l d \0
            ↑ strchr 返回这里
  打印它：printf("%s\n", p); → "o world"（从命中处到结尾）
  取下标：int idx = (int)(p - "hello world");  // 4
```

```c
char *p  = strchr ("hello world", 'o');  // "o world"
char *p2 = strrchr("hello world", 'o');  // "orld"（最后一个）
char *p3 = strstr ("hello world", "lo"); // "lo world"
if (p == NULL) { /* 没找到 */ }

char *ext = strrchr("main.c", '.');      // 取文件后缀
printf("%s\n", ext + 1);                 // "c"
```

**口诀**：三个返回都是指针，没找到就是 NULL；rchr 找最后。

## 7. sprintf / snprintf：把东西"写"进字符串

**人话**：printf 是往屏幕打，sprintf 是往字符串 buf 里打，格式一模一样。

```c
int sprintf (char *buf, const char *fmt, ...);          // 不检查长度！
int snprintf(char *buf, size_t n, const char *fmt, ...);// 最多写 n-1 字符 + '\0'
```

**为什么要用 snprintf**（实测）：
```c
char buf[6];
int n = snprintf(buf, sizeof buf, "%s", "hello world");
// buf = "hello"（只有 5 字符 + '\0'，被安全截断）
// n = 11  ← 注意：返回的是"本应写入"的长度，不是实际写入的！
if (n >= (int)sizeof buf) puts("被截断了");   // 用这个判断截断
```

⚠️ sprintf 不检查 buf 够不够 → 溢出。**一律用 snprintf。**

**口诀**：sprintf 不封顶会溢出，snprintf 限长又补零。

## 8. strtok：按分隔符"切"字符串

**人话**：给一个分隔符集合（如 `", "`），把串按分隔符切成一段一段，每次返回一段。

```c
char *strtok(char *s, const char *delim);
```

**内存图**：`char s[] = "one,two,,three";`
```
  第一次  strtok(s, ",")  → 找到第一个 ','，把它改成 '\0'，返回 "one"
          s 变成  one\0two,,three
  第二次  strtok(NULL, ",") → 从上次位置继续，返回 "two"
          s 变成  one\0two\0,three
  第三次  strtok(NULL, ",") → 遇到连续分隔符"，，"直接跳过，返回 "three"
  之后    strtok(NULL, ",") → 没段了，返回 NULL
```

```c
char s[] = "one,two,,three";
for (char *t = strtok(s, ","); t; t = strtok(NULL, ","))
    printf("[%s]\n");     // 输出 one / two / three（空字段被跳过）
```

**四个坑（实测）：**
1. **原串被改**：分隔符位置被写成 `'\0'`。想保留原串先 `strdup` 一份。
2. **第一次传串，之后传 NULL**：内部用静态指针记上次位置。
3. 连续分隔符当一个处理，得不到空字段。
4. **非线程安全**：静态变量，多线程用 `strtok_r`（POSIX）。

**口诀**：strtok 首传串后传 NULL，改原串非线程安全。

## 9. strdup 与输入输出三件套

**strdup**：`malloc` 一份然后把串拷进去，用完必须 `free`。
```c
char *copy = strdup("hello");
// ... 用 copy
free(copy);              // 不 free 就内存泄漏
```
⚠️ strdup 是 **POSIX** 函数，不是 C 标准。`-std=c99` 编译会报隐式声明警告；用 `-std=gnu99`（gcc 默认）或加 `#define _POSIX_C_SOURCE 200809L` 才干净。malloc 失败返回 NULL，严格场景要判空。

**puts**：输出一行 + **自动换行**，比 printf 简单。
```c
puts("hello");   // 等价于 printf("hello\n");
```

**fgets**：读一整行（含空格），最多读 n-1 个字符，必补 `'\0'`。
```c
char line[64];
if (fgets(line, sizeof line, stdin) != NULL) {
    line[strcspn(line, "\n")] = '\0';   // 惯用法：去掉结尾换行符
}
```

**scanf("%s") vs fgets（核心对比，必考）：**
| | `scanf("%s")` | `fgets` |
|---|---|---|
| 停止 | 遇空格/Tab/回车即停 | 读到回车为止（**保留空格**） |
| 越界 | ❌ 无保护（要 `%63s` 限宽） | ✅ 天然限长 |
| 换行 | 留在缓冲区，下次 %s 跳过 | **读进 buf 里**，要手动去 |
| 用途 | 读单个单词 | 读一整行 |

```c
// scanf("%s") 读单词、遇空格停：
char w[64]; scanf("%63s", w);     // 一定要限宽 %63s！
```

**口诀**：读一行用 fgets（去换行），读单词 scanf 要限宽。

## 10. 随堂任务：统计字符串中单词数量（状态机，含图解）

**题目**：输入一行英文，统计单词个数（单词 = 被 1 个或多个空格/Tab 隔开的连续字符段）。

**思路（别想复杂）**：用两个状态：当前"在不在单词里"。扫到空格 → 离开单词；从"不在"切到"在"的那一刻 → 计数 +1。

**状态机流程图**：
```
   开始
    │
    ▼
 ┌──────────┐   扫到 ' '/'\t'   ┌──────────┐
 │ 不在单词 │ ───────────────▶ │ 不在单词 │
 │ in=0     │                  │ in=0     │
 └──────────┘ ◀── 扫到非空白 ── └──────────┘
    │ 扫到非空白（从 0→1）           │
    ▼ count++                      │
 ┌──────────┐                     │
 │  在单词  │ ── 扫到空白 ──────────┘
 │  in=1    │
 └──────────┘
    （继续扫下一个字符）
```

**代码（实测通过，含边界）**：
```c
#include <stdio.h>
#include <string.h>

int count_words(const char *s) {
    int count = 0, in_word = 0;
    while (*s) {                       // 逐字符扫到 '\0'
        if (*s == ' ' || *s == '\t')
            in_word = 0;              // 空白 → 离开单词状态
        else if (!in_word) {
            in_word = 1;              // 空白后第一次碰到字 → 新单词开始
            count++;
        }
        s++;
    }
    return count;
}

int main(void) {
    char line[256];
    if (fgets(line, sizeof line, stdin) == NULL) return 1;
    line[strcspn(line, "\n")] = '\0'; // 去换行
    printf("%d\n", count_words(line));
    return 0;
}
```

**实测边界**：`"hello   c world"` → 3；`"  a b  "` → 2（首尾空格不算）；`""` → 0（空串）。全部正确。

**strtok 版（注意会破坏原串，需传可写数组）**：
```c
int count_words2(char *s) {
    int n = 0;
    for (char *t = strtok(s, " \t"); t; t = strtok(NULL, " \t"))
        n++;
    return n;
}
```

## 11. 追问预判（课堂口头回答，背这三句）

- **Q: strcpy 和 strncpy 哪个安全？**
  A: 都不够安全。strncpy 当 src 长度 ≥ n 时**不补 `'\0'`**，必须手动补；工程里更常用 **snprintf**，它保证结果一定是合法字符串。
- **Q: 为什么不能用 == 比字符串？**
  A: `==` 比的是两个数组的**首地址**，内容相同但位置不同的两个串地址不同，所以永远不相等。比内容用 `strcmp(a,b)==0`。
- **Q: strtok 之后为什么传 NULL？**
  A: 它内部用静态指针记住上次切到哪了，传 NULL 表示"接着上次的串继续切"。副作用：函数不可重入、多线程不安全（用 strtok_r）。
- **Q: strlen 复杂度？**
  A: O(n)，从头扫到 `'\0'`。所以别写 `for (i=0; i<strlen(s); i++)`（每轮重扫），先 `int len = strlen(s);`。

## 12. 一页速查卡（考前看这个）

| 想做的事 | 用哪个 | 别踩的雷 |
|---------|--------|---------|
| 求长度 | `strlen` | 返回无符号，别相减；≠sizeof |
| 拷贝整串 | `strncpy` + 手动补 `\0`，或 `snprintf` | dst 太小溢出 |
| 追加 | `strncat` | 字面量不能当 dst（只读） |
| 比内容 | `strcmp` | 别用 `==` |
| 找字符/子串 | `strchr/strrchr/strstr` | 返回指针，判 NULL |
| 格式化进串 | `snprintf` | 绝不 sprintf |
| 切分 | `strtok` | 破坏原串、非线程安全 |
| 复制一份 | `strdup` + `free` | POSIX 函数，要 gnu99 |
| 读一行 | `fgets` + 去换行 | 别用 gets（已废） |

> **嵌入式关联总结**：这一族函数在 MCU 上最关心两件事——① 缓冲区稀缺，strncpy/snprintf 的"限长"就是防栈溢出攻击的基本功；② 标准 printf/sprintf 体积大，嵌入式常用精简版（如 newlib-nano）或自己手写 my_snprintf——这也是面试高频手撕题（见练习 S3、S5）。

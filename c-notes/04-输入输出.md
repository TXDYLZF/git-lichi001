# 04 输入输出

## 一、基本认识

**结论**：C 语言本身**没有输入输出语句**，靠 `<stdio.h>` 里的库函数完成。

**为什么这样设计**：不同系统的 IO 机制完全不同（Linux 终端 vs Windows），C 把 IO 从语言剥离出来交给标准库去适配系统——这正是 C 能移植到各种平台的原因。

| 用途 | 函数 |
|------|------|
| 格式化输入输出 | `printf` / `scanf` |
| 单字符 | `getchar` / `putchar` |
| 字符串 | `fgets` / `puts` |

## 二、printf 格式符表

| 格式符 | 用途 | 修饰用法 | 效果 |
|--------|------|---------|------|
| `%d` | 有符号十进制 | `%5d` / `%-5d` | 右/左对齐占 5 位 |
| `%f` | 浮点（float/double 通用） | `%.2f` | 保留 2 位小数（四舍五入） |
| `%c` | 单字符 | | |
| `%s` | 字符串 | | |
| `%p` | 地址 | | |
| `%x` / `%o` | 十六进制 / 八进制 | `%#x` | 带 0x 前缀 |
| `%%` | 输出百分号本身 | | |

**记忆钩子**：`%.2f` 的点**在中间**——点是精度，前面的数是宽度。`%8.2f` = 总宽 8 位、含 2 位小数。

## 三、scanf 三大规则

### 规则 1：参数必须是地址

`scanf("%d", &a)` 传的是 a 的地址——scanf 要**改你的变量**，必须知道"住在哪"。

- 数组名本身就是地址，所以 `scanf("%s", buf)` **不加** `&`
- 和上节的解引用是一条线：`&` 把变量变地址，scanf 内部用 `*` 解引用去写

### 规则 2：返回值 = 成功读取的项数

```c
int r = scanf("%d", &n);
if (r != 1) {
    printf("输入的不是数字\n");   /* 用户敲字母时 %d 读不动，返回 0 */
}
```

**忽略返回值的死循环**：输入 `abc` 给 `scanf("%d", &n)`，abc 留在缓冲区谁也不消费，`while(scanf(...))` 无限循环。

### 规则 3：缓冲区残留（头号考点）

**实测过程**：

```
你敲入: 12⏎
缓冲区: [ '1' '2' '\n' ]
%d 吃掉 '1''2' → 停在 '\n' 前面
%c 上来 → 一口吃掉 '\n'   ← 惨案
```

实测输出：`第二个scanf读到: ASCII 10 (就是换行符!)`

**修复三选一**：

```c
scanf(" %c", &c);           /* %c 前加空格：跳过所有空白字符，最常用（实测有效） */
getchar();                  /* 手动吃掉一个残留字符 */
while (getchar() != '\n');  /* 清空整行残留 */
```

**警告**：网上教的 `fflush(stdin)` 是**未定义行为**，考试写出来扣分。

## 四、追问预判

| 问题 | 答法 |
|------|------|
| getchar 返回值为什么是 int？ | 要装下 `EOF`（值为 -1）。char 装不下所有合法字符 + EOF 的区别 |
| 怎么读到行尾为止？ | `while ((c = getchar()) != EOF)`。Windows 用 Ctrl+Z 回车结束，Linux 用 Ctrl+D |
| gets 能用吗？ | **不能用**，不检查长度会溢出，C11 已正式删除。用 `fgets(buf, sizeof(buf), stdin)`，最多读 sizeof-1 个字符。代价：会读进行尾 `\n`，需手动去掉 |
| printf 不加 \n 为什么看不见输出？ | 标准输出是**行缓冲**，没遇换行/缓冲满/程序结束就不刷出。嵌入式 printf 调试要加 `\n` 或 `fflush(stdout)` |

## 五、输入流结束的处理（实用技巧）

```c
if (scanf("%d", &guess) != 1) {
    if (feof(stdin)) {         /* 输入流结束了，体面退出 */
        printf("输入结束\n");
        break;
    }
    printf("请输入数字！\n");
    while (getchar() != '\n');  /* 清字母残留 */
    continue;
}
```

**写任何读输入的循环都要问一句：输入流没了会怎样？** 不检查 `feof` 会无限循环疯转（实测被系统 SIGTERM）。

## 六、嵌入式关联

单片机没有终端，`printf` 的去向要自己定——**重写 `fputc` 把它重定向到串口**：

```c
printf("temp=%d\r\n", t);   /* 从 UART 飞出去 */
```

这是所有嵌入式工程师的第一个 "Hello World 变体"。而 scanf 那套"传地址"的思路，到那边就是 **DMA 往内存地址搬数据**——本质都是"拿到地址才能写"。
